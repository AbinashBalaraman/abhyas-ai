# Emerging Technologies

## 1. Cloud Computing

### 1.1 What is Cloud Computing?

Cloud computing is the delivery of computing services (servers, storage, databases, networking, software) over the internet ("the cloud") to offer faster innovation, flexible resources, and economies of scale.

### 1.2 History

- **1960s**: J.C.R. Licklider envisioned "Intergalactic Computer Network"
- **2006**: Amazon launched AWS (Amazon Web Services) — first major cloud platform
- **2008**: Google App Engine launched
- **2010**: Microsoft Azure launched
- **Modern era**: Multi-cloud, hybrid cloud dominant

### 1.3 Cloud Service Models

| Model | Full Form | Description | Examples |
|---|---|---|---|
| **IaaS** | Infrastructure as a Service | Virtualized computing resources | AWS EC2, Google Compute Engine, Azure VM |
| **PaaS** | Platform as a Service | Platform for app development | Google App Engine, Heroku, Azure App Service |
| **SaaS** | Software as a Service | Ready-to-use software | Gmail, Office 365, Salesforce |
| **FaaS** | Function as a Service | Serverless computing | AWS Lambda, Azure Functions |
| **DaaS** | Desktop as a Service | Virtual desktop | AWS Workspaces, Azure Virtual Desktop |

### 1.4 Cloud Deployment Models

| Model | Description |
|---|---|
| **Public Cloud** | Services over public internet (AWS, Azure, GCP) |
| **Private Cloud** | Exclusive cloud for single organisation |
| **Hybrid Cloud** | Mix of public + private |
| **Community Cloud** | Shared by specific community |
| **Multi-cloud** | Multiple cloud providers |

### 1.5 Key Cloud Providers

| Provider | Service Name | Speciality |
|---|---|---|
| **Amazon** | AWS (Amazon Web Services) | Largest market share |
| **Microsoft** | Azure | Enterprise integration |
| **Google** | GCP (Google Cloud Platform) | AI/ML, data analytics |
| **IBM** | IBM Cloud | Hybrid cloud |
| **Oracle** | Oracle Cloud | Database services |
| **Alibaba** | Alibaba Cloud | Asian markets |

### 1.6 Popular Cloud Services

- **Google Drive**: 15GB free; file storage
- **OneDrive**: Microsoft cloud storage
- **Dropbox**: File hosting
- **iCloud**: Apple cloud service
- **AWS S3**: Object storage
- **Azure Blob Storage**: Microsoft cloud storage

### 1.7 Benefits of Cloud Computing
1. **Cost savings**: No upfront hardware investment
2. **Scalability**: Easily scale up/down
3. **Flexibility**: Access from anywhere
4. **Reliability**: Redundancy and disaster recovery
5. **Automatic updates**: Latest features
6. **Collaboration**: Multiple users
7. **Security**: Enterprise-grade

### 1.8 Cloud Computing Characteristics
- **On-demand self-service**
- **Broad network access**
- **Resource pooling**
- **Rapid elasticity**
- **Measured service**

## 2. Artificial Intelligence (AI)

### 2.1 What is AI?

AI is the simulation of human intelligence in machines that are programmed to think, learn, and solve problems autonomously.

### 2.2 History of AI

- **1950**: Alan Turing proposed "Turing Test"
- **1956**: Term "Artificial Intelligence" coined at Dartmouth Conference (by John McCarthy)
- **1960s-70s**: Early AI research; expert systems
- **1980s**: Machine learning emerges
- **1997**: IBM's Deep Blue beats Garry Kasparov (Chess)
- **2011**: IBM Watson wins Jeopardy
- **2012**: ImageNet breakthrough with deep learning
- **2016**: AlphaGo beats Lee Sedol (Go)
- **2022**: ChatGPT launched
- **2023-24**: Generative AI boom

### 2.3 Types of AI

| Type | Description | Example |
|---|---|---|
| **ANI (Artificial Narrow Intelligence)** | Specialised in one task | Voice assistants, chess AI |
| **AGI (Artificial General Intelligence)** | Human-level intelligence | Still theoretical |
| **ASI (Artificial Super Intelligence)** | Surpasses human intelligence | Future concept |

### 2.4 AI Subfields

1. **Machine Learning (ML)**: Systems learn from data
2. **Deep Learning (DL)**: Neural networks with many layers
3. **Natural Language Processing (NLP)**: Understanding human language
4. **Computer Vision**: Understanding images/videos
5. **Robotics**: Intelligent physical machines
6. **Expert Systems**: Mimicking human expert decisions
7. **Speech Recognition**: Converting speech to text

## 3. Machine Learning (ML)

### 3.1 What is ML?

Machine Learning is a subset of AI that enables systems to learn and improve from experience without being explicitly programmed.

### 3.2 Types of ML

| Type | Description | Example |
|---|---|---|
| **Supervised Learning** | Learns from labelled data | Image classification, spam detection |
| **Unsupervised Learning** | Finds patterns in unlabelled data | Customer segmentation, anomaly detection |
| **Reinforcement Learning** | Learns by trial and error | Game playing, robotics |

### 3.3 Common Algorithms

- **Linear Regression**: Predicting continuous values
- **Logistic Regression**: Binary classification
- **Decision Trees**: Tree-based decisions
- **Random Forest**: Ensemble of decision trees
- **Support Vector Machines (SVM)**: Classification
- **K-Nearest Neighbors (KNN)**: Classification
- **Neural Networks**: Deep learning
- **K-Means**: Clustering

### 3.4 Applications
- Recommendation systems (Netflix, YouTube)
- Fraud detection
- Medical diagnosis
- Spam filtering
- Autonomous vehicles
- Predictive analytics

## 4. Internet of Things (IoT)

### 4.1 What is IoT?

IoT refers to the network of physical devices (vehicles, appliances, sensors) connected to the internet, collecting and exchanging data.

### 4.2 History
- **1999**: Term "Internet of Things" coined by Kevin Ashton
- **2008-09**: Internet of Things recognised by CISCO
- **2010s**: Smart home devices emerge
- **2020s**: Industrial IoT, smart cities

### 4.3 Key Components

```
IoT Architecture
├── Sensors/Devices (collect data)
├── Connectivity (Wi-Fi, Bluetooth, 5G)
├── Cloud (storage and processing)
├── Analytics (insights)
└── User Interface (apps, dashboards)
```

### 4.4 Applications

| Domain | Application |
|---|---|
| **Smart Home** | Smart lights, thermostats, security |
| **Healthcare** | Wearables, remote monitoring |
| **Agriculture** | Smart irrigation, livestock tracking |
| **Industry** | Predictive maintenance, automation |
| **Smart Cities** | Traffic, pollution, energy management |
| **Retail** | Inventory tracking, smart shelves |
| **Transportation** | Fleet tracking, autonomous vehicles |

### 4.5 IoT Protocols
- **MQTT**: Lightweight messaging
- **CoAP**: Constrained Application Protocol
- **HTTP/HTTPS**: Web-based
- **Bluetooth Low Energy (BLE)**: Short range
- **LoRaWAN**: Long range, low power

## 5. Big Data

### 5.1 What is Big Data?

Big Data refers to extremely large datasets that cannot be processed by traditional database systems. Characterised by **5 V's**:

| V | Description |
|---|---|
| **Volume** | Terabytes to petabytes of data |
| **Velocity** | Speed of data generation (real-time) |
| **Variety** | Different types (structured, unstructured) |
| **Veracity** | Quality and accuracy of data |
| **Value** | Insights and business value |

### 5.2 Types of Big Data

- **Structured**: Tabular data (databases)
- **Unstructured**: Text, images, videos
- **Semi-structured**: JSON, XML

### 5.3 Big Data Technologies

| Technology | Function |
|---|---|
| **Hadoop** | Distributed storage and processing |
| **HDFS** | Hadoop Distributed File System |
| **MapReduce** | Programming model for parallel processing |
| **Spark** | Fast in-memory processing |
| **NoSQL** | Non-relational databases (MongoDB, Cassandra) |
| **Hive** | Data warehousing on Hadoop |
| **Pig** | High-level data flow |
| **Kafka** | Real-time streaming |

### 5.4 Applications
- Healthcare analytics
- Financial fraud detection
- Marketing analytics
- Recommendation systems
- Smart cities

## 6. Blockchain

### 6.1 What is Blockchain?

Blockchain is a distributed, decentralised, immutable ledger that records transactions across many computers in a way that cannot be altered retroactively.

### 6.2 Key Concepts

- **Block**: Contains batch of transactions
- **Chain**: Linked sequence of blocks
- **Hash**: Unique fingerprint of block
- **Decentralised**: No central authority
- **Immutable**: Cannot be changed
- **Consensus**: Agreement mechanism (Proof of Work, Proof of Stake)

### 6.3 How Blockchain Works

```
1. Transaction initiated
2. Transaction broadcast to peer-to-peer network
3. Network validates transaction
4. Validated transactions form new block
5. New block added to chain
6. Transaction complete
```

### 6.4 Types of Blockchain

| Type | Access | Examples |
|---|---|---|
| **Public** | Open to all | Bitcoin, Ethereum |
| **Private** | Restricted | Hyperledger, Corda |
| **Consortium** | Group of organisations | R3 |
| **Hybrid** | Mix of public + private | Dragonchain |

### 6.5 Applications

- **Cryptocurrencies**: Bitcoin, Ethereum
- **Smart Contracts**: Self-executing contracts
- **Supply Chain**: Track goods
- **Healthcare**: Secure patient records
- **Finance**: Cross-border payments
- **Voting**: Transparent elections
- **NFTs**: Digital ownership

### 6.6 Bitcoin
- First cryptocurrency (2008 - Satoshi Nakamoto)
- Uses blockchain technology
- Mining process for new bitcoins
- Limited supply: 21 million

### 6.7 Ethereum
- Open-source blockchain platform (2015 - Vitalik Buterin)
- Smart contracts
- Decentralised applications (DApps)
- Native cryptocurrency: Ether (ETH)

## 7. 5G Technology

### 7.1 What is 5G?

5G is the 5th generation mobile network technology, offering faster speeds, lower latency, and greater capacity than 4G.

### 7.2 Evolution of Mobile Networks

| Generation | Year | Technology | Speed |
|---|---|---|---|
| **1G** | 1980s | Analog | 2.4 kbps |
| **2G** | 1991 | GSM, Digital | 64 kbps |
| **3G** | 2001 | UMTS, CDMA | 2 Mbps |
| **4G** | 2009 | LTE, WiMAX | 100 Mbps-1 Gbps |
| **5G** | 2019+ | OFDM, mmWave | Up to 10 Gbps |

### 7.3 5G Features

- **Enhanced Mobile Broadband (eMBB)**: Faster speeds
- **Ultra-Reliable Low Latency (URLLC)**: <1ms latency
- **Massive Machine Type Communications (mMTC)**: IoT support
- **Speed**: Up to 10 Gbps
- **Latency**: <1 ms
- **Capacity**: 100x more devices than 4G

### 7.4 5G Use Cases
- Autonomous vehicles
- Smart cities
- Remote surgery
- AR/VR applications
- IoT
- Industrial automation

### 7.5 5G in India

- **2017**: 5G India 2020 Forum
- **2022**: 5G launched (Reliance Jio, Airtel)
- **Leading vendors**: Ericsson, Nokia, Samsung
- **Trial spectrum**: Allocated for testing

## 8. Other Emerging Technologies

### 8.1 Augmented Reality (AR)

- Overlays digital content on real world
- Examples: Pokemon Go, Google Glass, IKEA Place
- Technologies: ARKit (iOS), ARCore (Android)

### 8.2 Virtual Reality (VR)

- Immersive digital environment
- Head-mounted displays (HMDs)
- Examples: Oculus Quest, HTC Vive, PlayStation VR
- Use cases: Gaming, training, education

### 8.3 Mixed Reality (MR)

- Combines AR + VR
- Digital and physical interaction
- Examples: Microsoft HoloLens, Magic Leap

### 8.4 Quantum Computing

- Uses quantum bits (qubits)
- Superposition and entanglement
- Solves certain problems exponentially faster
- Companies: IBM (Q System One), Google (Sycamore), D-Wave

### 8.5 Edge Computing

- Processes data near the source (at the "edge")
- Reduces latency and bandwidth use
- Examples: Cloudflare, AWS Greengrass

### 8.6 DevOps

- Combination of Development + Operations
- CI/CD pipelines
- Tools: Docker, Kubernetes, Jenkins, Git

### 8.7 Robotic Process Automation (RPA)

- Software robots for repetitive tasks
- Examples: UiPath, Automation Anywhere, Blue Prism

## 10. Comparison Tables

### 10.1 IaaS vs PaaS vs SaaS

| Feature | IaaS | PaaS | SaaS |
|---|---|---|---|
| User controls | Apps, Data, OS | Apps, Data | Just use |
| Provider controls | Hardware, Network, Storage, Virtualisation | OS, Middleware, Runtime, Tools | Everything |
| Flexibility | High | Medium | Low |
| Examples | AWS EC2, Azure VM | Heroku, Google App Engine | Gmail, Office 365 |

### 10.2 AI vs ML vs DL

| Feature | AI | ML | DL |
|---|---|---|---|
| Scope | Broadest | Subset of AI | Subset of ML |
| Approach | Any technique | Statistical learning | Neural networks |
| Data | Variable | Structured | Large, unstructured |
| Compute | Variable | Moderate | High (GPUs) |

### 10.3 Public vs Private vs Hybrid Cloud

| Feature | Public | Private | Hybrid |
|---|---|---|---|
| Cost | Low upfront | High upfront | Mixed |
| Control | Less | More | Mixed |
| Security | Standard | Customisable | Mixed |
| Scalability | High | Limited | High |

### 10.4 4G vs 5G

| Feature | 4G | 5G |
|---|---|---|
| Speed | 100 Mbps-1 Gbps | Up to 10 Gbps |
| Latency | ~50 ms | <1 ms |
| Devices per sq km | ~100,000 | ~1,000,000 |
| Use cases | Streaming, basic IoT | AR/VR, autonomous, smart cities |
