# Chapter 4: Syllogism & Venn Diagrams

> **Chapter Overview:** Syllogism (deductive reasoning) and Venn Diagrams are **two interlocked reasoning tools** that appear in **3-5 questions per SSC CGL Tier-I**, **2-3 questions in IBPS PO Prelims/Mains**, **2 questions in SSC CHSL**, and **1-2 in RRB NTPC CBT-1**. Syllogism tests the ability to draw a logically valid conclusion from two or three given statements; Venn diagrams are the visual aid that makes syllogism solvable in seconds.
>
> **Comprehensive exam-aligned study material covering standard syllabi for SSC, RRB, Banking, and State PSC examinations.

## 1. Conceptual Foundation

### 1.1 What is Syllogism?

**Syllogism** is a form of **deductive reasoning** in which a conclusion is drawn from two (or more) statements called **premises**. The word comes from the Greek *syllogismos* ("conclusion" or "inference"). The structure is:

- **Major premise** (general statement)
- **Minor premise** (specific statement)
- **Conclusion** (follows from the two)

**Example**:
1. All human beings are mortal. *(Major premise)*
2. The child is a human being. *(Minor premise)*
3. The child is mortal. *(Conclusion)*

The conclusion is reached through a **middle term** ("human being"), which links the **subject** ("the child") and the **predicate** ("mortal"). The student must take the given premises as **universally true**, even if they sound absurd in real life.

> "The statements in Syllogism may very from commonly known facts and they sometimes appear impossible. But you have to take these statements to be true and ignore the actual meanings of the statements or terms used in the statements."

### 1.2 The Four Standard Forms (A, E, I, O)

In classical logic, every categorical statement is one of four forms. This is the universal vocabulary used by SSC, Banking, and UPSC examiners:

| Form | Name | Pattern | Example | Venn Diagram |
|------|------|---------|---------|--------------|
| **A** | Universal Affirmative | All A are B | All cats are animals | A circle inside B |
| **E** | Universal Negative | No A is B | No cat is a dog | Two separate circles |
| **I** | Particular Affirmative | Some A are B | Some cats are black | A and B circles overlap |
| **O** | Particular Negative | Some A are not B | Some cats are not black | A circle overlaps B; part of A outside B |

### 1.3 Three-Statement Syllogism: The SSC Standard

Modern SSC questions give **3 statements** and **2 conclusions**. The candidate must decide which conclusions **definitely follow**. The decision rules are:

1. **At least one premise must be affirmative.** Two negative premises → no conclusion.
2. **At least one premise must be universal.** Two particular premises → no conclusion.
3. **A negative conclusion requires at least one negative premise.**
4. **A particular conclusion requires at least one particular premise.**
5. **The middle term must be distributed in at least one premise.**
6. **If a term is distributed in the conclusion, it must be distributed in the premise.**

### 1.4 The "Either-Or" Case

When two conclusions are such that **both cannot be true simultaneously** (e.g., "All A are B" and "Some A are not B"), the answer is **"Either I or II follows"**. This is the most-tested trap in SSC CGL 2018-2025.

| Case | When |
|------|------|
| Both conclusions are **complementary** | "All A are B" + "Some A are not B" |
| The two conclusions form a **complete pair** | "All A are B" + "No A is B" |
| Same subject, same predicate | Different quantifiers that exhaust all possibilities |

### 1.5 Venn Diagrams: The Visual Solver

A **Venn diagram** is a closed-curve drawing in which each circle represents a class and the overlapping regions show how the classes are related. For SSC, three-circle Venns are the most tested.

**Three-circle Venn — Universal set U containing circles A, B, C:**

```
                    ___________
                  /             \
                 /     ___       \
                /    /     \      \
               |    |   A   |      |
               |    |       |   B  |
               |    |    ___|__   |
               |     \  /   |  \  |
               |      \/    |   \ |
               |      /\    | C  \|
               |     /  \   |    /|
               |    |    |  |   / |
               |    |    |  |  /  |
                \    \___/  | /  /
                 \          |/  /
                  \_________|__/
```

**Standard three-circle Venn showing 7 distinct regions** (the maximum number of non-overlapping regions in a 3-circle Venn):
- A only
- B only
- C only
- A ∩ B only (not C)
- A ∩ C only (not B)
- B ∩ C only (not A)
- A ∩ B ∩ C (centre)

Every syllogism-style Venn question reduces to one of these four visual patterns:

### 1.7 Two-Circle vs Three-Circle Problems

**Two-circle Venns** are tested in SSC Matric/CHSL; **three-circle Venns** dominate SSC CGL, Banking Mains, and Insurance AO. The standard three-circle interpretation rules:

| Statement | Venn Implication |
|-----------|------------------|
| "All A are B" | Draw A entirely inside B |
| "No A is B" | Draw A and B as separate, non-overlapping |
| "Some A are B" | Draw A and B with one common overlap region |
| "Some A are not B" | Draw A and B overlapping; part of A sticks out of B |
| "All A are B and all B are C" | A inside B inside C (chain) |
| "Some A are B and some B are C" | 3 circles with selective overlap |

### 1.8 Syllogism Vocabulary You Must Know

| Term | Definition | Example |
|------|-----------|---------|
| **Subject** | The thing being discussed | "cats" in "All cats are animals" |
| **Predicate** | What is being said about the subject | "animals" in "All cats are animals" |
| **Middle term** | The term common to both premises | "human being" in the example above |
| **Distributed term** | A term that refers to *all* members of its class | "All cats" — "cats" is distributed |
| **Particular statement** | Refers to *some* members | "Some cats" |
| **Universal statement** | Refers to *all* members | "All cats" / "No cats" |

## 2. Step-by-Step Solving Algorithm

### 2.1 For Syllogism (3 statements, 2 conclusions)

```
Step 1: Number the statements S1, S2, S3 and the conclusions C-I, C-II.
Step 2: Identify the quantifier of each:
        A = "All" (Universal + Affirmative)
        E = "No" (Universal + Negative)
        I = "Some" (Particular + Affirmative)
        O = "Some... are not" (Particular + Negative)
Step 3: Apply the 6 validity rules:
        (a) At least one premise must be affirmative.
        (b) At least one premise must be universal.
        (c) A negative conclusion needs at least one negative premise.
        (d) A particular conclusion needs at least one particular premise.
        (e) The middle term must be distributed in at least one premise.
        (f) If a term is distributed in the conclusion, it must be
            distributed in the premise.
Step 4: Cross-check by drawing a Venn diagram for the 3 statements.
        If C-I fits → I follows. If C-II fits → II follows.
Step 5: Check for "Either-Or" possibility (complementary conclusions).
Step 6: If only I fits → answer (a); only II → (b); both → (c);
        neither → (d); either-or → (e).
```

### 2.2 For Venn Diagram Problems

```
Step 1: Read the three statements carefully. List every quantifier.
Step 2: Start with the most restrictive statement (universal + negative
        takes priority, then universal + affirmative, then particular).
Step 3: Draw a 3-circle Venn:
        U = outer rectangle
        A = top-left circle
        B = top-right circle
        C = bottom circle
Step 4: For each statement, place the relationship on the Venn:
        "All X are Y" → X-circle entirely inside Y-circle
        "No X is Y"   → X-circle entirely outside Y-circle
        "Some X are Y" → mark a small overlap region between X and Y
        "Some X are not Y" → mark part of X outside Y
Step 5: Read the question. Find the option that is GUARANTEED TRUE
        or GUARANTEED FALSE by the diagram.
Step 6: Eliminate options that are POSSIBLE but not CERTAIN.
```

### 2.3 The 30-Second Venn Trick

For SSC CGL Tier-I, the fastest method is to **immediately draw a Venn** and read the answer. Most syllogism questions can be solved in 20-40 seconds this way.

**Master Venn for the four standard statements:**

```

3. No A is B:                  4. Some A are not B:
```

## 3. Trap Detection & Error Prevention Guide

Top 10 traps used in Syllogism + Venn Diagram questions:

1. **"Some" is always positive.** "Some A are B" = "Some B are A". "Some A are not B" is NOT reversible. Trap: assuming reversibility for negative statements.

2. **"All" + "No" double statement chain.** "All A are B, all B are C" → A inside B inside C. Conclusion "All A are C" follows. But "All C are A" does NOT follow. Trap: assuming symmetric.

3. **"No A is B" does NOT mean "All A are not B" in everyday English.** In logic they are the same. Trap: misreading the negation.

4. **"Some A are B" + "Some A are C" does NOT mean "Some B are C".** Trap: assuming shared predicate creates a triangle.

5. **"Either-Or" conclusions.** When two conclusions together cover all cases (e.g., "All A are B" + "Some A are not B"), exactly one MUST be true. Trap: marking both as following.

6. **Two-particular-premise silence.** If both premises start with "Some", no universal conclusion can be drawn. Trap: trying to deduce an "All".

7. **Complement pair trap.** "Some A are B" and "Some A are not B" together form a complete pair (exhaust all A). The answer becomes "Either I or II follows".

8. **Hidden "All" implied by "No".** "No A is B" implies "All A are not-B" — used to derive an "All" conclusion when only "No" is given. Trap: ignoring this implication.

9. **Three-statement transitive chain.** With "All A are B" + "All B are C" + "All C are D", the chain "All A are D" follows. With a single negative link (e.g., "No B is C"), the chain **breaks**.

10. **Venn "Possibly True" vs "Definitely True".** For "Which is definitely true?" — find what the Venn *forces*. For "Which could be true?" — find what the Venn *allows*. Trap: confusing the two directions.

### 3.1 Sample trap sentence + correct interpretation

> **Trap sentence:** "If all cats are animals and some animals are wild, then some cats are wild."
> **Correct interpretation:** WRONG. "All cats are animals" places cats inside animals. "Some animals are wild" creates an overlap between animals and wild. But the *wild part of animals* may or may not include the *cat part*. We cannot conclude.

## 4. Type-Wise Question Bank with Solutions

### Type 1: Three-Statement Two-Conclusion (SSC CGL Standard)

**Logic:** 3 statements + 2 conclusions; determine which definitely follow using the 6 validity rules + Venn verification.
**Difficulty:** Easy-Medium
**Exam Source:** SSC CGL Tier-I, SSC CHSL, SSC CPO, IBPS PO Mains

**Solved Example 1 (SSC Style — 1 min):**
> Statements:
> S1: All pens are books.
> S2: All books are bags.
> S3: No bag is a box.
> Conclusions:
> I. Some pens are not boxes.
> II. At least some bags are pens.
>
> **Solution:**
>
> Step 1 (Venn): Pens → inside Books → inside Bags. Bags separate from Box.
>
> ```
> Box
> _______________
> | _______ |
> | / Books \ |
> | | Pens | |
> | | | |
> | \______/ |
> |_______________|
> ```
>
> Step 2: I. "Some pens are not boxes" — Pens are inside Books which are inside Bags; Bags don't overlap with Box. Therefore Pens don't overlap with Box. Some pens are not boxes = TRUE (definitely true).
>
> Step 3: II. "At least some bags are pens" — All pens are inside bags; therefore some bags contain pens. TRUE.
>
> **Answer: (c) Both I and II follow.**

**Solved Example 2 (IBPS PO Mains — Hard — 2 min):**
> Statements:
> S1: Some apples are mangoes.
> S2: All mangoes are fruits.
> S3: No fruit is vegetable.
> Conclusions:
> I. Some apples are not vegetables.
> II. Some fruits are mangoes.
>
> **Solution:**
>
> Step 1: Venn: Apples ∩ Mangoes (overlap). All Mangoes ⊂ Fruits. Fruits ∩ Vegetables = ∅.
>
> ```
> ___________
> / Veggies \
> | __________ |
> | / \ |
> |/ ___ ___ \|
> || /Ap \/M \ ||
> || \ / \__/ ||
> || __\_/ ___ ||
> ||/ Fruits \ ||
> || ||
> |\___________/||
> |_____________|
> ```
>
> Step 2: I. Some apples (those that are mangoes, which are inside Fruits, which don't intersect with Vegetables) are not vegetables. TRUE.
>
> Step 3: II. All mangoes are fruits, so some fruits are mangoes. TRUE.
>
> **Answer: (c) Both I and II follow.**
>

**Solved Example 3 (RRB NTPC — 30 sec):**
> Statements:
> S1: All dogs are animals.
> S2: All animals are living beings.
> Conclusions:
> I. All dogs are living beings.
> II. Some living beings are dogs.
>
> **Solution:** Transitive: Dogs ⊂ Animals ⊂ Living Beings. Therefore both conclusions follow.
>
> **Answer: (c) Both I and II follow.**

### Type 2: The "Either-Or" Case

**Logic:** Two complementary conclusions where exactly one must be true.
**Difficulty:** Medium
**Exam Source:** SSC CGL Tier-I (2018+), Banking Mains

**Solved Example:**
> Statements:
> S1: All cars are vehicles.
> S2: Some vehicles are red.
> Conclusions:
> I. All cars are red.
> II. Some cars are not red.
>
> **Solution:**
> Cars ⊂ Vehicles. Vehicles ∩ Red = partial overlap. Cars may or may not be in the red portion of Vehicles. Conclusion I says all cars are red — not necessarily. Conclusion II says some cars are not red — not necessarily either (cars might all be red). The two are complementary: either all cars are red OR some cars are not red. They cannot both be false.
>
> **Answer: (e) Either I or II follows.**

### Type 3: Two-Circle Venn Diagram (SSC Matric Level)

**Logic:** Two overlapping classes, conclusions about representation in regions.
**Difficulty:** Easy
**Exam Source:** SSC MTS, SSC CHSL

**Solved Example:**
> Statement: "In a class of 50 students, 30 play cricket and 20 play football. 10 play both. How many play only cricket?"
>
> **Solution:**
> ```
> ___________
> / ____ \
> | /C \ |
> | | __ |
| \ / F \ |
> \ \/____\/ /
> \__________/
> ```
> Cricket only = Total Cricket − Both = 30 − 10 = 20.
>
> **Answer: 20**
>

### Type 4: Three-Circle Venn (SSC CGL Standard)

**Logic:** Three classes with overlaps, count or identify a specific region.
**Difficulty:** Medium-Hard
**Exam Source:** SSC CGL, Banking Mains, Insurance AO

**Solved Example:**
> Statement: In a survey of 100 people, 60 like Tea, 50 like Coffee, 40 like Milk. 20 like Tea and Coffee, 15 like Tea and Milk, 10 like Coffee and Milk, 5 like all three. How many like only Tea?
>
> **Solution:**
> ```
> ___________
> / ___ \
> | / T \ |
> | | 5 | |
> | | __ | |
> | /C \_/ M |
> | | X |
> | \___/____|
> ```
>
> Use inclusion-exclusion: |T only| = |T| − (T∩C only) − (T∩M only) − (all 3)
> = 60 − (20 − 5) − (15 − 5) − 5
> = 60 − 15 − 10 − 5 = 30.
>
> **Answer: 30**
>

### Type 5: Coded Syllogism (Banking Mains)

**Logic:** Statements use symbols like @, #, $, %, & instead of words; conclusions also coded.
**Difficulty:** Hard
**Exam Source:** IBPS PO Mains, SBI PO Mains, RBI Grade B

**Solved Example:**
> Statements:
> S1: A @ B means "All A are B"
> S2: A # B means "No A is B"
> S3: A $ B means "Some A are B"
>
> Question: "Pen @ Book, Book # Box" → Conclusions:
> I. Pen $ Box
> II. Pen # Box
>
> **Solution:** Pen ⊂ Book; Book ∩ Box = ∅. Therefore Pen ∩ Box = ∅, so Pen # Box. Conclusion II follows. Conclusion I says "Some pen are box" = false (none). Hence only II follows.
>
> **Answer: (b) Only II follows.**
>

### Type 6: Negative Premise Conclusions

**Logic:** One premise is "No", conclusions derive certainty from separation.
**Difficulty:** Medium
**Exam Source:** SSC CGL, SSC CPO

**Solved Example:**
> Statements:
> S1: All doctors are engineers.
> S2: No engineer is a teacher.
> Conclusions:
> I. No doctor is a teacher.
> II. Some engineers are doctors.
>
> **Solution:** Doctors ⊂ Engineers. Engineers ∩ Teacher = ∅. Therefore Doctors ∩ Teacher = ∅. I follows. II is also true because doctors are inside engineers (some engineers are doctors). Both follow.
>
> **Answer: (c) Both I and II follow.**

### Type 7: Possibility / Definite Conclusions

**Logic:** Mix of "definitely true" and "could be true" conclusions.
**Difficulty:** Hard
**Exam Source:** SSC CGL Tier-II, Banking Mains

**Solved Example:**
> Statements:
> S1: Some A are B.
> S2: All B are C.
> Conclusions:
> I. Some A are definitely C.
> II. Some A could be outside C.
>
> **Solution:** A overlaps B; B ⊂ C. So the part of A inside B is also inside C. Therefore some A are definitely C. But A could extend outside B (since "Some A are B" doesn't say all A are B). The part of A outside B is not in C. So some A could be outside C.
>
> **Answer: Both I and II are correct in their respective senses.** In MCQ, "Both" follows.
>

## 5. Timed Practice Sets

### Set A — Warm-Up (5 questions, 30-45 sec each)

**Q1.** Statements: All cats are dogs. All dogs are birds.
Conclusions: I. Some cats are birds. II. All birds are cats.
- (a) Only I follows (b) Only II follows (c) Both follow (d) Neither follows
**Solution:** Cats ⊂ Dogs ⊂ Birds. So I follows (some cats = those cats that are also dogs = inside birds). II is wrong because not all birds are cats (dogs are also birds).
**Answer: (a)**

**Q2.** Statements: Some A are B. No B is C.
Conclusions: I. Some A are not C. II. No A is C.
- (a) Only I follows (b) Only II follows (c) Both follow (d) Neither follows
**Solution:** The A part overlapping B doesn't intersect with C (since B doesn't intersect with C). So some A are not C follows. But other A (outside B) might or might not intersect C. So "No A is C" doesn't follow.
**Answer: (a)**

**Q3.** Statements: All X are Y. Some Y are Z.
Conclusions: I. Some X are Z. II. Some X may not be Z.
- (a) Only I follows (b) Only II follows (c) Both follow (d) Neither follows
**Solution:** X ⊂ Y. The X part of Y may or may not overlap with Z (some Y are Z means part of Y is Z). So II (some X may not be Z) is certain. I is not definite.
**Answer: (b)**

**Q4.** Statements: All cars are vehicles. Some vehicles are red.
Conclusions: I. All cars are red. II. Some cars are not red.
- (a) Only I follows (b) Only II follows (c) Both follow (d) Neither follows (e) Either I or II follows
**Solution:** Cars ⊂ Vehicles. Vehicles ∩ Red is partial. Cars could all be red, or could include non-red cars. Hence the two conclusions form a complementary pair.
**Answer: (e)**

**Q5.** Statements: No mango is apple. Some apples are bananas.
Conclusions: I. Some mangoes are bananas. II. No mango is banana.
- (a) Only I follows (b) Only II follows (c) Both follow (d) Neither follows (e) Either I or II follows
**Solution:** Mangoes ∩ Apples = ∅. The apple-banana overlap is outside mangoes. So mangoes may or may not overlap with bananas. The two conclusions are complementary.
**Answer: (e)**

### Set B — Exam Simulation (2 puzzle sets of 5 questions, 5-7 min per set)

**Set B1: SSC CGL Tier-I Standard (3 statements, 2 conclusions)**

**Q6.** Statements: All metals are solids. All solids are heavy. No heavy is light.
Conclusions: I. Some metals are not light. II. No solid is light.
- (a) Only I follows (b) Only II follows (c) Both follow (d) Neither follows
**Solution:** Metals ⊂ Solids ⊂ Heavy. Heavy ∩ Light = ∅. Therefore Metals ∩ Light = ∅ and Solids ∩ Light = ∅. Both follow.
**Answer: (c)**

**Q7.** Statements: Some boys are tall. All tall are smart. No smart is weak.
Conclusions: I. Some boys are not weak. II. All boys are smart.
- (a) Only I follows (b) Only II follows (c) Both follow (d) Neither follows
**Solution:** Boys ∩ Tall → Smart → not-Weak. The boys-in-tall section is smart, hence not weak. So I follows. "All boys are smart" requires all boys to be tall, which we don't have.
**Answer: (a)**

**Q8.** Statements: All cats are animals. Some animals are wild. Some wild are dangerous.
Conclusions: I. Some cats may be dangerous. II. Some animals are not dangerous.
- (a) Only I follows (b) Only II follows (c) Both follow (d) Neither follows
**Solution:** Cats ⊂ Animals. Animals ∩ Wild is partial. Wild ∩ Dangerous is partial. The cat part of animals could intersect with wild and dangerous (transitively) but not necessarily. I is possible. "Some animals are not dangerous" — since dangerous only comes via wild, animals outside wild are not dangerous. So II is definite.
**Answer: (b)**

**Q9.** Statements: All pens are pencils. Some pencils are erasers. No eraser is sharpener.
Conclusions: I. Some pens are not sharpeners. II. Some pencils are not sharpeners.
- (a) Only I follows (b) Only II follows (c) Both follow (d) Either I or II follows
**Solution:** Pens ⊂ Pencils. Some Pencils are Erasers. Erasers ∩ Sharpeners = ∅. The pencil-eraser part is not sharpeners. But pencil-non-eraser part may or may not be sharpeners. So II is definite (some pencils = those that are erasers = not sharpeners). I follows because pens ⊂ pencils, and the pencil-eraser part is inside pencils. Hence pens that are inside the eraser intersection are not sharpeners.
**Answer: (c)**

**Q10.** Statements: All rivers are water bodies. Some water bodies are polluted. All polluted are harmful.
Conclusions: I. Some rivers are harmful. II. Some rivers are not polluted.
- (a) Only I follows (b) Only II follows (c) Both follow (d) Either I or II follows
**Solution:** Rivers ⊂ Water bodies. Water bodies ∩ Polluted is partial. All Polluted ⊂ Harmful. The polluted part of water bodies is harmful. Whether this part includes rivers is unclear (depends on whether the polluted-water-body part overlaps rivers). So I is possible, II is also possible. But are they definite? No, both are possibilities. The two together form a complementary pair ONLY if they cover all cases — they don't necessarily.
**Answer: (c)** — Both I and II are "possibly true". In exam, this is often treated as both following.

**Set B2: Banking Mains — Harder**

**Q11.** Statements: Some a are b. All b are c. No c is d.
Conclusions: I. Some a are not d. II. No b is d.
- (a) Only I (b) Only II (c) Both (d) Either
**Solution:** a ∩ b → c → not-d. The a-b overlap is in c, hence not-d. So I follows (some a = those a that are b = not-d). b ⊂ c, and c ∩ d = ∅, so b ∩ d = ∅. Hence II follows (no b is d).
**Answer: (c)**

**Q12.** Statements: Every X is Y. Every Y is Z. Some Z is W. No W is V.
Conclusions: I. All X are W. II. Some X are V.
- (a) Only I follows (b) Only II follows (c) Both follow (d) Neither follows
**Solution:** X ⊂ Y ⊂ Z. Z ∩ W is partial. Z ∩ V = ∅ (since W ∩ V = ∅ and Z ∩ W might be empty of V, but Z itself is not restricted against V). Actually, Z could intersect V (only W is restricted against V). So X may or may not be in W or V. I doesn't follow (not all X are W). II doesn't follow (some X might be V, but not necessarily).
**Answer: (d)**

**Q13.** Statements: All engineers are graduates. Some graduates are employed. All employed are rich.
Conclusions: I. Some engineers are rich. II. Some rich are engineers.
- (a) Only I (b) Only II (c) Both (d) Neither
**Solution:** Engineers ⊂ Graduates. Some Graduates are Employed. Employed ⊂ Rich. The engineer-graduate-employed-rich chain could pass through, but it's not certain that engineers overlap with employed. So I is "possible", not definite. "Some rich are engineers" is also only possible.
**Answer: (d)** — Neither definitely follows. (Both are POSSIBLE only.)

**Q14.** Statements: All A are B. All C are B. No A is C.
Conclusions: I. Some B are not A. II. Some B are not C.
- (a) Only I (b) Only II (c) Both (d) Neither
**Solution:** A ⊂ B, C ⊂ B. A ∩ C = ∅. A and C are disjoint subsets of B. Since B has elements (it contains A and C), some B are not A (those that are C) — I follows. Similarly some B are not C — II follows.
**Answer: (c)**

**Q15.** Statements: Some cats are dogs. All dogs are pets. Some pets are wild.
Conclusions: I. Some cats are wild. II. Some dogs are wild.
- (a) Only I (b) Only II (c) Both (d) Either (e) Neither
**Solution:** Cats ∩ Dogs (some). Dogs ⊂ Pets. Pets ∩ Wild (partial). The cat-dog overlap is in Pets. But does it overlap with Wild? Not necessarily. So neither is definite. II: dogs ⊂ pets, and pets ∩ wild is partial; the dog part of pets may or may not be in the wild part. So II is also only possible, not definite.
**Answer: (e)**

### Set C — Advanced (3 questions, IBPS PO Mains / SBI PO Mains level)

**Q16.** Statements: A @ B (Some A are B). B # C (No B is C). C $ D (Some C are D).
Conclusions: I. A @ D (Some A are D). II. D # A (No D is A).
- (a) Only I follows (b) Only II follows (c) Both follow (d) Neither follows
**Solution:** A ∩ B ≠ ∅. B ∩ C = ∅. C ∩ D ≠ ∅. The A-B overlap is outside C (since B is outside C). C-D overlap is inside C. So A and D are in disjoint regions. Neither I nor II follows.
**Answer: (d)**

**Q17.** Statements: All A are B. No B is C. Some C are D. All D are E.
Conclusions: I. Some E are not A. II. Some A may be D.
- (a) Only I (b) Only II (c) Both (d) Neither
**Solution:** A ⊂ B. B ∩ C = ∅. C ∩ D ≠ ∅. D ⊂ E. The C-D overlap is in C, hence outside B (since B ∩ C = ∅). D ⊂ E, but D might also intersect with B? D ⊂ C? No — D includes C ∩ D and other parts. Some D could be outside C, but D is inside E. The part of E that comes from C-D is outside B, hence outside A. So some E (those from C-D chain) are not A — I follows. For II: A is in B. D could be in C (which is outside B) or outside C (could be in B). If some D is in B, it could be in A. So II is possible, not definite.
**Answer: (a)**

**Q18.** Statements: Some books are pens. Some pens are pencils. All pencils are erasers.
Conclusions: I. Some books are erasers. II. Some books may not be erasers.
- (a) Only I follows (b) Only II follows (c) Both follow (d) Either I or II follows
**Solution:** Books ∩ Pens. Pens ∩ Pencils. Pencils ⊂ Erasers. The book-pen-pencil chain may or may not overlap. So I is possible (not definite). II is also possible. Together they form a complementary pair? Not exactly, because both could be false (if no books are pencils). Wait — if some books are pens and some pens are pencils, the chain might or might not transmit. Both possibilities exist.
**Answer: (c)** Both are possible.

## 6. Quick Revision Sheet

### 6.1 Core Rules in Bullet Form

1. **A** (All A are B): A ⊂ B. Subject distributed.
2. **E** (No A is B): A ∩ B = ∅. Both distributed.
3. **I** (Some A are B): A ∩ B ≠ ∅. Neither distributed.
4. **O** (Some A are not B): Some A outside B. Only subject distributed.
5. **"All" + "All" transitive:** If All A are B and All B are C, then All A are C.
6. **"Some" is NOT transitive:** Some A are B and Some B are C does NOT mean Some A are C.
7. **"No" breaks transitive:** If All A are B and No B is C, then No A is C. Negative universal breaks any chain.
8. **Two negative premises → no conclusion.**
9. **Two particular premises → no universal conclusion (but some particular conclusions possible).**
10. **Either-Or trigger:** "All A are B" + "Some A are not B" (complementary on subject A).

### 6.2 Decision Tree

| If you see... | Then do... |
|---------------|------------|
| "All A are B" + "All B are C" | Draw chain: A ⊂ B ⊂ C |
| "No A is B" + "All C are A" | Draw C ⊂ A, then C ∩ B = ∅ |
| "Some A are B" + "No B is C" | A ∩ B ≠ ∅ is outside C |
| "Some A are B" + "Some B are C" | Don't assume transitive — Venn needed |
| "Either I or II" option | Check if I and II are complementary |
| "Possibly true" question | Mark what Venn *allows*, not what it *forces* |
| "Definitely true" question | Mark what Venn *forces* |
| "Definitely false" question | Mark what Venn *forbids* |

### 6.3 Time Allocation Guide

| Question Type | Time | Strategy |
|---------------|------|----------|
| 3-stmt 2-conclusion standard | 30-45 sec | Use Venn directly |
| Either-or case | 45-60 sec | Identify complement pair |
| Possibility/definite | 60-90 sec | Read carefully, distinguish |
| Coded syllogism | 60-90 sec | Translate symbols first, then solve |
| 3-circle Venn counting | 90-120 sec | Use inclusion-exclusion formula |
| 4-statement syllogism | 90-120 sec | Reduce to 3-statement chains |

### 6.4 The Inclusion-Exclusion Formula

For three sets A, B, C:
$$|A \cup B \cup C| = |A| + |B| + |C| - |A \cap B| - |B \cap C| - |A \cap C| + |A \cap B \cap C|$$

This is the most-tested formula in Venn-based counting problems (SSC CGL, Banking Mains).

### 6.5 The 7 Most Common Syllogism Conclusions to Check

1. **All A are C** (transitive universal affirmative)
2. **Some A are C** (transitive particular affirmative)
3. **No A is C** (negative universal transitive)
4. **Some A are not C** (negative particular)
5. **All A are B** (reversal of premises — usually false)
6. **Some B are A** (converse of "Some A are B" — always true)
7. **Either-Or complementary** (when conclusions exhaust the subject)
