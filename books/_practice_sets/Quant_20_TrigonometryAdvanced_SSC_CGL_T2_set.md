## Q4. sin 2A (Medium)
If $\tan A = 4/3$, find $\sin 2A$.
(a) 24/25  (b) 7/25  (c) 8/25  (d) 14/25

**Answer:** (a) 24/25
**Solution:** $\sin\theta = 4/5, \cos\theta = 3/5$. $\sin 2\theta = 2(4/5)(3/5) = 24/25$
**Shortcut:** Convert to sin, cos.

## Q6. cos 2A (Medium)
If $\sin A = 3/5$ (QI), find $\cos 2A$.
(a) 7/25  (b) -7/25  (c) 16/25  (d) -16/25

**Answer:** (a) 7/25
**Solution:** $\cos A = 4/5$. $\cos 2A = 1 - 2\sin^2 A = 1 - 2(9/25) = 1 - 18/25 = 7/25$.
**Shortcut:** $\cos 2A = 1 - 2\sin^2 A$.
**Common Mistake:** Sign error.
**Time target:** 60 sec

## Q7. Product to Sum (Hard)
$\sin 75° \cos 15° = ?$
(a) $\frac{2 + \sqrt{3}}{4}$  (b) $\frac{1 + \sqrt{3}/2}{2}$  (c) Both  (d) None

**Answer:** (c) Both
**Solution:** $\sin 75 \cos 15 = \frac{1}{2}[\sin 90 + \sin 60] = \frac{1}{2}[1 + \sqrt{3}/2] = (2 + \sqrt{3})/4$.
**Shortcut:** Product-to-sum formula.
**Common Mistake:** Not using the formula.
**Time target:** 120 sec

## Q8. tan Sum (Hard)
$\tan 75° = ?$
(a) $2 + \sqrt{3}$  (b) $2 - \sqrt{3}$  (c) $\sqrt{3}$  (d) $1/\sqrt{3}$

**Answer:** (a) $2 + \sqrt{3}$
**Solution:** $\tan(45° + 30°) = \frac{1 + 1/\sqrt{3}}{1 - 1/\sqrt{3}} = \frac{\sqrt{3} + 1}{\sqrt{3} - 1} = 2 + \sqrt{3}$
**Shortcut:** tan 75 = tan(45+30).
**Common Mistake:** Sign in denominator.
**Time target:** 90 sec

## Q12. Inverse Sum (Hard)
$\sin^{-1}(1) + \cos^{-1}(1) = ?$
(a) 0  (b) π/2  (c) π  (d) 2π

**Answer:** (b) π/2
**Solution:** $\sin^{-1}(1) = \pi/2, \cos^{-1}(1) = 0$. Sum = π/2. Or use identity.
**Shortcut:** $\sin^{-1}x + \cos^{-1}x = \pi/2$.
**Common Mistake:** Confusing values.
**Time target:** 45 sec

## Q13. Half Angle (Medium)
If $\cos\theta = 1/2$, find $\cos(\theta/2)$.
(a) 1/2  (b) √3/2  (c) 1/√2  (d) 1

**Answer:** (b) √3/2
**Solution:** $\cos(\theta/2) = \pm\sqrt{(1+\cos\theta)/2} = \sqrt{(1+1/2)/2} = \sqrt{3/4} = \sqrt{3}/2$
**Shortcut:** Half angle formula.
**Common Mistake:** Forgetting ±.
**Time target:** 90 sec

---

## Q14. Triangle Trigonometry (Hard)
In a right triangle, if one acute angle is 30°, the other is:
(a) 30°  (b) 45°  (c) 60°  (d) 90°

**Answer:** (c) 60°
**Solution:** Sum of acute angles in right triangle = 90°. So 90° - 30° = 60°.
**Shortcut:** Sum = 90° in right triangle.
**Common Mistake:** Returning 30°.
**Time target:** 30 sec
