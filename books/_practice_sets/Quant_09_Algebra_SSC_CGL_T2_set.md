## Q1. Common root (Medium)
If x² + ax + b = 0 and x² + bx + a = 0 have a common root, then (assume a ≠ b):
(a) a + b = 0  (b) a + b = 1  (c) a + b = −1  (d) a + b = 2

**Answer:** (c) −1
**Solution:** Subtract: (a−b)x + (b−a) = 0 → (a−b)(x−1) = 0. If a ≠ b, x = 1. Sub in first: 1 + a + b = 0 → a + b = −1. ✓
**Shortcut:** Subtract equations.
**Common Mistake:** Forgetting a ≠ b condition.
**Time target:** 60 sec

## Q2. Remainder theorem (Medium)
Remainder when x³ − 3x² + 5x − 7 is divided by (x − 2):
(a) −1  (b) 1  (c) 0  (d) 2

**Answer:** (a) −1
**Solution:** P(2) = 8 − 12 + 10 − 7 = −1. ✓
**Shortcut:** P(a) = remainder.
**Common Mistake:** Doing long division.
**Time target:** 60 sec

## Q3. Sophie Germain (Medium)
Factor x⁴ + 4:
(a) (x²+2x+2)(x²−2x+2)  (b) (x²+1)²  (c) (x²+2)²  (d) (x²−2)²

**Answer:** (a) (x²+2x+2)(x²−2x+2)
**Solution:** x⁴ + 4 = (x²+2)² − (2x)² = (x²+2x+2)(x²−2x+2). ✓
**Shortcut:** Sophie Germain identity.
**Common Mistake:** Treating as (x²+2)².
**Time target:** 75 sec

## Q4. a³ + b³ (Hard)
If a + b = 6, ab = 8, find a³ + b³:
(a) 72  (b) 96  (c) 120  (d) 144

**Answer:** (a) 72
**Solution:** a³+b³ = (a+b)³ − 3ab(a+b) = 216 − 3·8·6 = 216 − 144 = 72. ✓
**Shortcut:** (a+b)³ − 3ab(a+b).
**Common Mistake:** Using (a³+b³) = (a+b)(a²−ab+b²) directly.
**Time target:** 60 sec

## Q5. x + 1/x cubed (Hard)
If x + 1/x = 3, find x³ + 1/x³:
(a) 18  (b) 24  (c) 27  (d) 36

**Answer:** (a) 18
**Solution:** x³+1/x³ = (x+1/x)³ − 3(x+1/x) = 27 − 9 = 18. ✓
**Shortcut:** Identity.
**Common Mistake:** Just cubing.
**Time target:** 60 sec

## Q6. Rationalization (Hard)
Rationalize 1/(√5 − √3):
(a) (√5+√3)/2  (b) √5+√3  (c) √5−√3  (d) 1

**Answer:** (a) (√5+√3)/2
**Solution:** Multiply by (√5+√3)/(√5+√3): (√5+√3)/(5−3) = (√5+√3)/2. ✓
**Shortcut:** Multiply by conjugate.
**Common Mistake:** Missing division by 2.
**Time target:** 60 sec

## Q8. Quadratic with condition (Hard)
If x² + 2x + k = 0 has equal roots, k = ?
(a) 0  (b) 1  (c) 2  (d) 4

**Answer:** (b) 1
**Solution:** D = 4 − 4k = 0 → k = 1. ✓
**Shortcut:** D = 0 for equal roots.
**Common Mistake:** Wrong discriminant setup.
**Time target:** 30 sec

## Q9. Algebraic fraction (Hard)
Simplify (x²−9)/(x²−4x+3) for x ≠ 1, 3:
(a) (x+3)/(x−1)  (b) (x−3)/(x+1)  (c) (x+3)/(x+1)  (d) (x−3)/(x−1)

**Answer:** (a) (x+3)/(x−1)
**Solution:** (x−3)(x+3) / ((x−1)(x−3)) = (x+3)/(x−1). ✓
**Shortcut:** Factor both.
**Common Mistake:** Missing cancellation.
**Time target:** 60 sec

## Q10. Word problem (Hard)
A father is 3 times his son's age. After 8 years, sum will be 64. Son's present age:
(a) 10  (b) 12  (c) 14  (d) 16

**Answer:** (b) 12
**Solution:** 3S+S+16 = 64 → 4S = 48 → S = 12. ✓
**Shortcut:** Substitute F=3S.
**Common Mistake:** Forgetting to add 8 to both.
**Time target:** 60 sec

## Q11. Sum of roots product (Hard)
If α, β are roots of x² − 5x + 6 = 0, find α² + β²:
(a) 11  (b) 13  (c) 25  (d) 36

**Answer:** (b) 13
**Solution:** α+β = 5, αβ = 6. α²+β² = (α+β)² − 2αβ = 25 − 12 = 13. ✓
**Shortcut:** Vieta's then identity.
**Common Mistake:** Confusing (a+b)² with a²+b².
**Time target:** 60 sec

## Q12. Special identity (Very Hard)
If a + b + c = 0, then a³ + b³ + c³ equals:
(a) 0  (b) 3abc  (c) abc  (d) (a+b+c)³

**Answer:** (b) 3abc
**Solution:** a³+b³+c³−3abc = (a+b+c)(...) = 0, so a³+b³+c³ = 3abc. ✓
**Shortcut:** Standard identity.
**Common Mistake:** Forgetting the 3.
**Time target:** 90 sec

## Q13. Equation transformation (Very Hard)
If x + 1/x = 5, find x² + 1/x²:
(a) 23  (b) 25  (c) 27  (d) 21

**Answer:** (a) 23
**Solution:** (x+1/x)² = x²+2+1/x² = 25 → x²+1/x² = 23. ✓
**Shortcut:** Square and subtract 2.
**Common Mistake:** Forgetting subtract 2.
**Time target:** 60 sec

## Q14. Discriminant application (Very Hard)
For x² + kx + 9 = 0 to have real roots, k² should be:
(a) ≥ 36  (b) ≥ 18  (c) ≥ 9  (d) ≤ 36

**Answer:** (a) ≥ 36
**Solution:** D = k² − 36 ≥ 0 → k² ≥ 36. ✓
**Shortcut:** D ≥ 0.
**Common Mistake:** Sign of 4ac.
**Time target:** 60 sec

## Q15. Surd rationalization cubic (Very Hard — Trap)
Rationalize 1/(∛2 − 1):
(a) ∛4 + ∛2 + 1  (b) ∛2 + 1  (c) ∛4 − ∛2 + 1  (d) 1

**Answer:** (a) ∛4 + ∛2 + 1
**Solution:** Use a³−b³ = (a−b)(a²+ab+b²). 1/(∛2−1) = (∛4+∛2+1)/((∛2)³−1³) = (∛4+∛2+1)/(2−1) = ∛4+∛2+1. ✓
**Shortcut:** Sum of cube cubes identity.
**Common Mistake:** Conjugate with square.
**Time target:** 120 sec
