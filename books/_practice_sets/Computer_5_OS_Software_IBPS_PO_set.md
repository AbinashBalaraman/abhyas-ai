### Q1. The "M" in "RAM" stands for:
(a) Memory (b) Module (c) Both (a) and (b) (d) Mode

**Answer: (a) Memory**

**Solution:** The "M" in RAM stands for Memory. RAM (Random Access Memory) is the main memory of the computer, used to store data and instructions currently being processed. The "Random Access" part means any byte can be accessed directly without going through other bytes (unlike sequential access in magnetic tape). RAM is volatile (loses data on power off). Types: SRAM (Static RAM - faster, used for cache) and DRAM (Dynamic RAM - cheaper, used as main memory). Modern RAM: DDR4, DDR5 SDRAM. RAM is faster than secondary storage (HDD, SSD) but more expensive per byte.

### Q2. The "R" in "ROM" stands for:
(a) Random (b) Read (c) Run (d) Real

**Answer: (b) Read**

**Solution:** The "R" in ROM stands for Read. ROM (Read Only Memory) is non-volatile memory. The data in ROM is typically written once and read many times. ROM is used to store boot firmware (BIOS/UEFI), and other permanent data. Types: ROM (programmed at factory, cannot be erased), PROM (Programmable ROM - can be programmed once), EPROM (Erasable PROM - erased by UV light, can be reprogrammed), EEPROM (Electrically Erasable PROM - erased by electric current, used for BIOS updates). Flash memory is a type of EEPROM. Modern computers use flash-based ROM. ROM is essential for booting the computer.

### Q3. SSD uses which type of memory?
(a) Magnetic (b) Optical (c) Flash (d) RAM

**Answer: (c) Flash**

**Solution:** SSD (Solid State Drive) uses Flash memory (specifically NAND Flash) to store data. NAND Flash is a non-volatile memory that retains data without power. SSD has no moving parts, making it faster (μs access time), more durable, lighter, and consumes less power than HDD. SSD uses interfaces: SATA, NVMe (PCIe), M.2. Modern NVMe SSDs can reach 7,000+ MB/s read/write speeds. Flash memory was invented by Dr. Fujio Masuoka (Toshiba, 1980s). SSD is replacing HDD in most applications due to its speed advantage. The main types of Flash memory: NOR Flash (used in BIOS) and NAND Flash (used in SSD, USB drives, memory cards).

### Q4. The Operating System is an example of:
(a) Application software (b) System software (c) Programming software (d) Utility software

**Answer: (b) System software**

**Solution:** The Operating System (OS) is an example of System Software. System software manages hardware and software resources and provides services to application software. Functions of OS: Process Management, Memory Management, File Management, Device Management, Security & Access Control, User Interface. Examples: Windows (Microsoft), macOS (Apple), Linux (open-source), Android (Google), iOS (Apple). The OS is the master program that runs on a computer. Other types of software: Application software (Word, Excel, Photoshop), Programming software (compilers, interpreters, IDEs), Utility software (antivirus, disk cleanup, backup).

MS Word formatting shortcuts also include: Ctrl + L (Left align), Ctrl + E (Centre align), Ctrl + R (Right align), Ctrl + J (Justify). The font formatting shortcuts work in most text editors and word processors. They are essential for efficient document creation.

### Q8. The Ctrl + Y shortcut in MS Word is used to:
(a) Undo (b) Redo (c) Cut (d) Copy

**Answer: (b) Redo**

**Solution:** Ctrl + Y in MS Word is used to Redo. Redo is the opposite of Undo. If you Undo an action and then want to redo it, you use Ctrl + Y. Ctrl + Z is Undo. The Undo/Redo function allows you to revert or reapply changes in a document. Other useful shortcuts: Ctrl + Z (Undo), Ctrl + Y (Redo), Ctrl + C (Copy), Ctrl + V (Paste), Ctrl + X (Cut), Ctrl + A (Select All), Ctrl + S (Save), Ctrl + F (Find), Ctrl + H (Replace). The Undo/Redo shortcut is one of the most useful features for editing documents without fear of losing work.

### Q9. The "Ctrl + X" shortcut in MS Word is used to:
(a) Copy (b) Cut (c) Paste (d) Undo

**Answer: (b) Cut**

**Solution:** Ctrl + X in MS Word is used to Cut. The Cut operation removes the selected text and stores it in the clipboard. Ctrl + C is Copy (without removing), and Ctrl + V is Paste (from the clipboard). The Cut-Copy-Paste shortcuts (Ctrl + X, Ctrl + C, Ctrl + V) are fundamental in any text editor. They work in MS Word, Excel, PowerPoint, browsers, and most applications. The clipboard can hold one item at a time in standard use. The Cut operation is useful when you want to move text from one place to another.

### Q10. The "Ctrl + Z" shortcut in MS Word is used to:
(a) Redo (b) Cut (c) Undo (d) Copy

**Answer: (c) Undo**

Other useful shortcuts: Ctrl + X (Cut), Ctrl + C (Copy), Ctrl + V (Paste), Ctrl + A (Select All), Ctrl + S (Save), Ctrl + F (Find), Ctrl + H (Replace).
