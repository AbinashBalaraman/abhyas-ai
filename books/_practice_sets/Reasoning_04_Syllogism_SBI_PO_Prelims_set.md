### Q1. Statements:
S1: All apples are fruits.
S2: All fruits are healthy.
Conclusions:
I. All apples are healthy.
II. Some healthy are apples.
(a) Only I (b) Only II (c) Both (d) Neither

**Answer:** (c) Both
**Solution:** Apples → Fruits → Healthy. I ✓. II: reversible ✓.
**Time Target:** 25 sec |

### Q2. Statements:
S1: Some keys are locks.
S2: All locks are metal.
Conclusions:
I. Some keys are metal.
II. Some metal are keys.
(a) Only I (b) Only II (c) Both (d) Neither

**Answer:** (c) Both
**Solution:** Keys ∩ Locks ≠ ∅. Locks inside Metal. Keys ∩ Metal ≠ ∅ ✓. Reversible ✓.
**Time Target:** 30 sec |

### Q3. Statements:
S1: No bird is a fish.
S2: All fish live in water.
Conclusions:
I. No bird lives in water.
II. Some non-birds live in water.
(a) Only I (b) Only II (c) Both (d) Neither

**Answer:** (b) Only II
**Solution:** Birds separate from Fish. All fish in water doesn't mean no bird in water. I doesn't follow. II: "All fish live in water" → "Some non-birds (fish) live in water" ✓.
**Time Target:** 40 sec |

### Q4. Statements:
S1: Some A are B.
S2: Some B are C.
S3: All C are D.
Conclusions:
I. Some A are D.
II. Some D are A.
(a) Only I (b) Only II (c) Both (d) Neither

**Answer:** (d) Neither
**Solution:** A ∩ B ≠ ∅. B ∩ C ≠ ∅. C inside D. No definite A-D or D-A link.
**Time Target:** 35 sec |

### Q5. Statements:
S1: All P are Q.
S2: No Q is R.
S3: Some S are Q.
Conclusions:
I. Some S are not R.
II. No S is R.
(a) Only I (b) Only II (c) Both (d) Either/Or

**Answer:** (a) Only I
**Solution:** S ∩ Q ≠ ∅. Q separate from R. So some S (in Q) are not R ✓. II: S may have parts not in Q, which could be R.
**Time Target:** 40 sec |

### Q7. Statements:
S1: Some M are N.
S2: No N is O.
Conclusions:
I. Some M are not O.
II. Some O are not M.
(a) Only I (b) Only II (c) Both (d) Either/Or

**Solution:** "All birds can fly" is a universal statement, so logically ✓. But penguins can't actually fly — but in syllogism, premises are taken as true.
