**Answer: (c) Calibri**

### Q6. SQL stands for:
(a) Simple Query Language (b) Structured Query Language (c) Sequential Query Language (d) Standard Query Language

**Answer: (b) Structured Query Language**

**Solution:** SQL stands for Structured Query Language. It is the standard language for managing relational databases. SQL was developed at IBM in the 1970s (originally called SEQUEL - Structured English QUEry Language). SQL is used to define, manipulate, and retrieve data from relational databases. SQL commands: DDL (Data Definition Language) - CREATE, ALTER, DROP; DML (Data Manipulation Language) - SELECT, INSERT, UPDATE, DELETE; DCL (Data Control Language) - GRANT, REVOKE; TCL (Transaction Control) - COMMIT, ROLLBACK. SQL is supported by all major RDBMS: Oracle, MySQL, SQL Server, PostgreSQL, DB2. SQL is standardized by ANSI/ISO.

### Q7. Which command is used to retrieve data in SQL?

### Q8. A Primary Key must be:
(a) Null (b) Unique (c) Duplicate (d) Foreign

**Answer: (b) Unique**

**Solution:** A Primary Key must be UNIQUE and NOT NULL. Each row in a table must have a unique Primary Key value. The Primary Key uniquely identifies each row/record in a table. A table can have only one Primary Key, but it can be a composite key (multiple columns). A Foreign Key is a column in one table that refers to the Primary Key in another table, establishing a relationship. Other SQL constraints: UNIQUE (no duplicates), NOT NULL (cannot be empty), CHECK (condition), DEFAULT (default value). Primary Keys can be auto-incremented (e.g., IDENTITY in SQL Server, AUTO_INCREMENT in MySQL, SERIAL in PostgreSQL).

### Q9. The full form of DBMS is:
(a) Data Backup Management System (b) Database Management System (c) Database Manipulation System (d) Data Management System

**Answer: (b) Database Management System**

**Solution:** DBMS stands for Database Management System. It is software that allows users to define, create, maintain, and manipulate databases. Examples: MySQL, Oracle, SQL Server, PostgreSQL, MongoDB. DBMS functions: Data definition, Data storage, Data retrieval, Data manipulation, Data security, Data integrity, Backup & recovery. RDBMS (Relational DBMS) stores data in tables (relations) and uses SQL for queries. RDBMS examples: Oracle, MySQL, MS SQL Server, PostgreSQL, IBM DB2. Modern DBMS supports ACID properties (Atomicity, Consistency, Isolation, Durability).

### Q10. ACID properties relate to:
(a) Hardware (b) Database transactions (c) Networking (d) Programming

**Answer: (b) Database transactions**

**Solution:** ACID properties relate to database transactions. ACID stands for Atomicity, Consistency, Isolation, Durability. These are the key properties that guarantee database transactions are processed reliably. Atomicity: All or nothing (a transaction is fully completed or not at all). Consistency: Valid state transitions (database goes from one valid state to another). Isolation: Concurrent transactions are independent (no interference). Durability: Committed data persists (survives system failures). RDBMS supports ACID. NoSQL databases often relax some ACID properties for scalability (BASE - Basically Available, Soft state, Eventually consistent).

### Q14. Which is a NoSQL database?
(a) MySQL (b) Oracle (c) MongoDB (d) SQL Server

**Answer: (c) MongoDB**

**Solution:** MongoDB is a NoSQL database. Other NoSQL databases: Redis (key-value), Cassandra (column-family), HBase, Neo4j (graph), CouchDB (document), DynamoDB. NoSQL databases do not use the traditional relational model. They are used for big data, real-time web apps, and flexible schema needs. Types of NoSQL: Document (MongoDB, CouchDB), Key-Value (Redis, DynamoDB), Column-Family (Cassandra, HBase), Graph (Neo4j). In contrast, MySQL, Oracle, and SQL Server are traditional SQL/RDBMS. NoSQL databases often relax ACID for scalability (BASE - Basically Available, Soft state, Eventually consistent).

### Q15. Normalisation is used to:
(a) Increase data redundancy (b) Reduce data redundancy (c) Delete data (d) Encrypt data

**Answer: (b) Reduce data redundancy**

**Solution:** Normalisation is the process of organising data in a database to reduce redundancy and improve data integrity. The normal forms (most common): 1NF (First Normal Form) - atomic values, no repeating groups; 2NF - 1NF + no partial dependencies; 3NF - 2NF + no transitive dependencies; BCNF (Boyce-Codd Normal Form) - stricter 3NF. Higher normal forms: 4NF, 5NF. Normalisation is a key concept in RDBMS design. Over-normalisation can lead to performance issues due to excessive joins, so sometimes denormalisation is used for performance. The process of designing a normalised database is called "Database Normalisation".
