### Q1. Ctrl + F in MS Word is used to:
(a) Print (b) Save (c) Find (d) Copy

**Answer: (c) Find**

**Solution:** Ctrl + F in MS Word is used to Find text. The Find dialog box allows you to search for specific text in the document. It has options like Match Case, Find Whole Words Only, etc. Ctrl + H is used to Find and Replace. Ctrl + G is used for Go To (specific page, section, etc.). Other useful shortcuts: Ctrl + N (New), Ctrl + O (Open), Ctrl + S (Save), Ctrl + P (Print), Ctrl + A (Select All). MS Word has many keyboard shortcuts that improve productivity. The Find feature is also available in browsers, PDF readers, and other text-based applications. Find and Replace is one of the most time-saving features in MS Word.

### Q2. Ctrl + H in MS Word is used to:
(a) Save (b) Find and Replace (c) Print (d) Open

**Answer: (b) Find and Replace**

**Solution:** Ctrl + H in MS Word is used for Find and Replace. It allows you to search for text and replace it with new text. The Find and Replace dialog box has options: Find what, Replace with, Match Case, Find Whole Words Only, etc. Other useful shortcuts: Ctrl + F (Find), Ctrl + N (New), Ctrl + O (Open), Ctrl + S (Save), Ctrl + P (Print), Ctrl + A (Select All), Ctrl + C (Copy), Ctrl + V (Paste), Ctrl + X (Cut), Ctrl + Z (Undo), Ctrl + Y (Redo). The Find and Replace feature is also available in PowerPoint, Excel, browsers, and other text-based applications. It is a powerful editing tool.

### Q3. Ctrl + C in MS Word is used to:
(a) Cut (b) Copy (c) Paste (d) Undo

**Answer: (b) Copy**

**Solution:** Ctrl + C in MS Word (and most applications) is used to Copy the selected text. The copied text is stored in the clipboard. Ctrl + X is used to Cut (copy + delete). Ctrl + V is used to Paste the copied/cut text. These shortcuts work in almost all applications (Word, Excel, PowerPoint, browsers, etc.). The clipboard can hold one item at a time in standard use, but multiple items with clipboard managers. The Cut, Copy, Paste shortcuts are fundamental for any text editing. They save a lot of time and are used extensively in office work.

**Time Target:** 30s | **Chapter Reference:** Computer/02_Hardware_Software.md, p.330-345 | **VERIFY:** No

### Q4. The Ctrl + V shortcut is used for:
(a) Copy (b) Cut (c) Paste (d) Save

**Answer: (c) Paste**

**Solution:** Ctrl + V in MS Word (and most applications) is used to Paste the text from the clipboard. The clipboard contains the text that was previously Copied (Ctrl + C) or Cut (Ctrl + X). These three shortcuts (Ctrl + C, Ctrl + X, Ctrl + V) form the basic Copy-Paste operation. They work in almost all applications. The paste operation can sometimes include formatting (rich text paste) or plain text only. Modern applications also support paste special options (Ctrl + Shift + V). The clipboard can hold text, images, files, and other data types.

### Q5. The F1 key in MS Word is used to:
(a) Save (b) Print (c) Help (d) Open

**Answer: (c) Help**

**Solution:** The F1 key in MS Word (and most applications) is used to open Help. Microsoft Word's Help provides information on features, troubleshooting, and tutorials. F1 is the universal Help key across Microsoft Office and Windows. Other F-key shortcuts in MS Word: F2 (Rename), F5 (Go To), F7 (Spelling and Grammar check), F12 (Save As), Ctrl + F1 (Expand/Collapse Ribbon), Shift + F1 (Reveal Formatting). Modern Office also has a "Tell Me" feature (search bar) for finding features and help.

### Q6. The F2 key in Windows is used to:
(a) Help (b) Rename (c) Find (d) Refresh

**Answer: (b) Rename**

**Solution:** The F2 key in Windows File Explorer is used to Rename the selected file or folder. Other F-key shortcuts in Windows: F1 (Help), F2 (Rename), F3 (Search), F5 (Refresh), F6 (Cycle through elements), F10 (Activate menu bar), F11 (Fullscreen toggle in browsers), F12 (Save As in Word). These F-key shortcuts are used across Windows and many applications. F2 is one of the most useful shortcuts for file management. The F-keys are the top row keys on a standard keyboard. F-keys often have alternate functions (Fn + F-key on laptops).

### Q7. The F5 key in a browser is used to:
(a) Help (b) Refresh (c) Save (d) Find

**Answer: (b) Refresh**

**Solution:** The F5 key in a web browser is used to Refresh the current page. It reloads the page from the server. Ctrl + F5 is used for a hard refresh (no cache). F5 also works in Windows File Explorer to refresh the current view. Other F-key shortcuts: F1 (Help), F2 (Rename), F3 (Search), F6 (Cycle through elements), F7 (Spelling check in Word), F10 (Activate menu bar), F11 (Fullscreen toggle), F12 (Developer Tools in browsers). F5 is one of the most commonly used F-key shortcuts. Hard refresh (Ctrl + F5) is useful when the page is not updating properly.

### Q8. The F11 key is used to:
(a) Help (b) Save (c) Fullscreen toggle (d) Print

**Answer: (c) Fullscreen toggle**

**Solution:** The F11 key is used to toggle Fullscreen mode in most browsers (Chrome, Firefox, Edge). It hides the address bar, tabs, and bookmarks bar for a distraction-free view. Pressing F11 again exits fullscreen mode. F11 also works in many other applications (PDF readers, image viewers, video players). F11 is one of the most useful shortcuts for presentations and reading. Other F-key shortcuts: F1 (Help), F2 (Rename), F3 (Search), F5 (Refresh), F12 (Developer Tools). The F11 fullscreen is different from Windows' fullscreen (Win + Shift + Enter) which is used in UWP apps.

### Q9. Alt + Tab is used to:
(a) Switch windows (b) Close window (c) Open new window (d) Refresh

**Answer: (a) Switch windows**

**Solution:** Alt + Tab is used to Switch between open windows in Windows. It shows a visual switcher (Task Switcher) that allows you to cycle through open applications. Holding Alt and pressing Tab multiple times cycles through windows. Releasing Alt switches to the selected window. Alt + Shift + Tab cycles in reverse. Alt + Tab is one of the most commonly used Windows shortcuts. It improves productivity by allowing quick switching between applications. Other Windows shortcuts: Win + D (Desktop), Win + E (File Explorer), Win + L (Lock), Win + Tab (Task View), Ctrl + Alt + Delete (Security options).

**Time Target:** 30s | **Chapter Reference:** Computer/02_Hardware_Software.md, p.348-355 | **VERIFY:** No

### Q10. Alt + F4 is used to:
(a) Switch windows (b) Close program (c) Open new window (d) Refresh

**Answer: (b) Close program**

**Solution:** Alt + F4 is used to Close the current program (or window). In Windows, this is the universal shortcut to close the active window. If multiple programs are open, it closes the active one. If the desktop is active, it opens the Shut Down Windows dialog. Alt + F4 is one of the most commonly used Windows shortcuts. Other Windows shortcuts: Alt + Tab (Switch windows), Ctrl + W (Close current window in browsers), Ctrl + Shift + N (New incognito in Chrome), Win + D (Desktop), Win + L (Lock). The combination Alt + F4 is sometimes called "Alt F4" colloquially and is well-known among Windows users.

**Time Target:** 30s | **Chapter Reference:** Computer/02_Hardware_Software.md, p.349-355 | **VERIFY:** No

### Q11. The Ctrl + A shortcut is used to:
(a) Save (b) Print (c) Select All (d) Copy

**Answer: (c) Select All**

**Solution:** Ctrl + A in MS Word (and most applications) is used to Select All. It selects all the content in the current document, file, or window. In a word processor, it selects all text. In a file explorer, it selects all files/folders. In a browser, it can select all content on the page. Other useful shortcuts: Ctrl + C (Copy), Ctrl + V (Paste), Ctrl + X (Cut), Ctrl + Z (Undo), Ctrl + Y (Redo), Ctrl + F (Find), Ctrl + H (Replace), Ctrl + S (Save). The Select All shortcut is useful when you want to apply formatting to all content or delete everything.

### Q12. The Ctrl + P shortcut in MS Word is used to:
(a) Print (b) Save (c) Copy (d) Open

**Answer: (a) Print**

**Solution:** Ctrl + P in MS Word is used to Print the current document. It opens the Print dialog box where you can choose a printer, set print options, and preview the document. Other useful shortcuts: Ctrl + N (New), Ctrl + O (Open), Ctrl + S (Save), Ctrl + W (Close current document), Ctrl + F (Find), Ctrl + H (Replace), Ctrl + Z (Undo), Ctrl + Y (Redo). The Print dialog has options: number of copies, page range, printer selection, duplex (double-sided) printing, paper size, and orientation (portrait/landscape). MS Word can also export to PDF.

### Q13. Ctrl + N in MS Word is used to:
(a) Open existing document (b) Create new document (c) Save document (d) Print document

**Answer: (b) Create new document**

**Solution:** Ctrl + N in MS Word is used to Create a New (blank) document. Other document management shortcuts: Ctrl + O (Open existing document), Ctrl + S (Save), Ctrl + W (Close current document), Ctrl + P (Print). These shortcuts are standard across Microsoft Office applications. When you press Ctrl + N, MS Word creates a new blank document based on the Normal template. You can also use File > New to choose from templates. The new document uses the default settings (font Calibri 11, page size Letter/A4, 1-inch margins).

### Q14. Ctrl + O in MS Word is used to:
(a) Create new document (b) Open existing document (c) Save document (d) Close document

**Answer: (b) Open existing document**

**Solution:** Ctrl + O in MS Word is used to Open an existing document. The Open dialog box allows you to navigate to the file location. Other document management shortcuts: Ctrl + N (Create new document), Ctrl + S (Save), Ctrl + W (Close current document), Ctrl + P (Print). MS Word supports various file formats: .docx (current), .doc (legacy), .rtf (Rich Text Format), .txt (Plain Text), .pdf (PDF), .odt (OpenDocument), and more. Recent files are also shown in the File > Recent menu for quick access.

### Q15. Ctrl + W in MS Word is used to:
(a) Save (b) Print (c) Close current document (d) Open

**Answer: (c) Close current document**

**Solution:** Ctrl + W in MS Word is used to Close the current document. If there are unsaved changes, MS Word prompts to save. Ctrl + W also closes the current tab in browsers (Chrome, Firefox, Edge). Other shortcuts: Ctrl + N (New), Ctrl + O (Open), Ctrl + S (Save), Ctrl + P (Print), Ctrl + Q (Quit - quits MS Word). The keyboard shortcut to close MS Word itself is Alt + F4 or Ctrl + Q. Note: Ctrl + W closes the current document, while Alt + F4 closes the entire MS Word application.
