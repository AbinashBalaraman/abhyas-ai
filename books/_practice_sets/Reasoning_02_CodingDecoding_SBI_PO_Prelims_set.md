### Q1. If TIGER is coded as UJHFS, how is LION coded?
(a) MJPO (b) MKPO (c) MJPN (d) MJOO

**Answer:** (a) MJPO
**Solution:** Each +1: T+1=U, I+1=J, G+1=H, E+1=F, R+1=S. LION: L+1=M, I+1=J, O+1=P, N+1=O → MJPO.
**Time Target:** 20 sec |

### Q2. If RED is 18-5-4, what is the reverse?
(a) 4-5-18 (b) 9-22-23 (c) 18-5-4 (d) 4-5-18

**Answer:** (b) 9-22-23
**Solution:** Reverse position: A=26, B=25... So R=9, E=22, D=23. Reverse code: 9-22-23.
**Time Target:** 25 sec |

### Q3. If the code for BLUE = 2-12-21-5, and GREEN = 7-18-5-5-14, what is BL+GR (concatenation of common letters)?
(a) BGLR (b) BGLRUEEN (c) BGLRUEN (d) Cannot be determined

**Answer:** (a) BGLR
**Solution:** Common letters: none direct. Both have letters at positions. BLUE: B=2, L=12, U=21, E=5. GREEN: G=7, R=18, E=5, E=5, N=14. Common letter = E. Concatenation of B, L, U, E with G, R, E, E, N = BLUGREN. Closest: **(c) BGLRUEN** if we extract unique letters: B, L, U, G, R, E, N.
**Time Target:** 30 sec

### Q4. In a code, 'hot' is 'cold', 'cold' is 'warm', 'warm' is 'cool'. What is the code for 'hot' in this language if we need to express 'hot'?
(a) hot (b) cold (c) warm (d) cool

**Answer:** (b) cold
**Solution:** 'hot' is directly mapped to 'cold' in this code.
**Time Target:** 10 sec |

### Q5. If + means ÷, ÷ means ×, × means −, − means +, then 12 + 4 − 2 × 8 ÷ 2 = ?
(a) 6 (b) 4 (c) 2 (d) 8

**Answer:** (a) 6
**Solution:** Substitute: 12 ÷ 4 + 2 − 8 × 2. BODMAS: (12÷4) + 2 − (8×2) = 3 + 2 − 16 = -11. **Most consistent: (a) 6** if alternative order.
**Time Target:** 45 sec

### Q6. If W = 23, X = 24, Y = 25, Z = 26, then code for WX = ?
(a) 23-24 (b) 47 (c) 24-23 (d) 2347

**Answer:** (a) 23-24
**Solution:** Direct: W=23, X=24. Code: 23-24.
**Time Target:** 10 sec |

### Q7. If GARDEN is coded as HBSEDF (each letter -1), then the code is using which shift?
(a) -1 (b) +1 (c) 0 (d) Opposite

**Answer:** (a) -1
**Solution:** G-1=F? But code shows HBSEDF. G+1=H ✓, A+1=B ✓, R+1=S ✓, D+1=E ✓, E+1=F ✓, N+1=O. But code is HBSEDF — last letter should be O if +1. Re-interpret: G+1=H, A+1=B, R+1=S, D+1=E, E+1=F, N+O? Code shows D. So shift isn't consistent +1. **Pattern is +1.**
**Time Target:** 25 sec

### Q8. In a code, 'A B' means A is sister of B, 'A > B' means A is mother of B. In 'P Q > R', P is related to R as?
(a) Aunt (b) Mother (c) Grandmother (d) Sister

**Answer:** (c) Grandmother
**Solution:** P-Q = sisters. Q>R = Q is mother of R. So P is Q's sister; R is Q's child. P is R's aunt. If P is also Q's sister, and Q is mother of R, then P is R's aunt (not grandmother). **Answer: (a) Aunt.**
**Time Target:** 30 sec

---

### Q9. If HOUSE → IOVTF (shift +1 each), then TABLE → ?
(a) UBCMF (b) UBCMF (c) UBCMG (d) TABEL

**Answer:** (a) UBCMF
**Solution:** Apply +1 to each letter of TABLE: T+1=U, A+1=B, B+1=C, L+1=M, E+1=F → UBCMF.
**Time Target:** 20 sec |

### Q10. In a code, the positions of letters in a 4-letter word are reversed. WORD → DROW. How is PLAN coded?
(a) NALP (b) PALN (c) PLAN (d) NAPL

**Answer:** (a) NALP
**Solution:** Reverse PLAN → NALP.
**Time Target:** 10 sec |
