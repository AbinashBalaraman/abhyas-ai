### Q1. Who is known as the "Father of the Computer"?
(a) Blaise Pascal (b) Charles Babbage (c) John Napier (d) Herman Hollerith

**Answer: (b) Charles Babbage**

**Solution:** Charles Babbage is known as the "Father of the Computer". He invented the Difference Engine (1822) and the Analytical Engine (1837), which is considered the first mechanical computer. The Analytical Engine used punched cards (inspired by Jacquard loom) and had components similar to modern computers. Lady Ada Augusta Lovelace was a student of Babbage and is considered the first computer programmer. Blaise Pascal invented the Pascaline (1642), an early mechanical calculator. John Napier invented Napier's Bones (1617). Herman Hollerith invented the Tabulating Machine (1890), used for the US Census.

### Q2. The first computer programmer was:
(a) Charles Babbage (b) Lady Ada Augusta Lovelace (c) Herman Hollerith (d) John Napier

**Answer: (b) Lady Ada Augusta Lovelace**

**Solution:** Lady Ada Augusta Lovelace (1815-1852) was a student of Charles Babbage and is considered the first computer programmer. She wrote what is considered the first algorithm intended to be processed by a machine (for the Analytical Engine). She worked on Babbage's Analytical Engine and wrote notes on it, including what is now recognized as the first algorithm. The programming language "Ada" is named after her. Charles Babbage is the "Father of the Computer" (not the programmer). Herman Hollerith invented the Tabulating Machine. John Napier invented Napier's Bones.

### Q3. ENIAC was developed in:
(a) 1944 (b) 1946 (c) 1949 (d) 1951

**Answer: (b) 1946**

**Solution:** ENIAC (Electronic Numerical Integrator and Computer) was developed in 1946. It was the first general-purpose electronic digital computer. ENIAC was developed by J. Presper Eckert and John Mauchly at the University of Pennsylvania. ENIAC used 17,468 vacuum tubes, weighed 30 tons, and occupied a large room. EDVAC (1949) was the first stored-program computer, designed by John von Neumann. UNIVAC-I (1951) was the first commercial computer, also by Eckert and Mauchly. Mark-I (1944) by Howard Aiken was an electro-mechanical computer.

### Q4. Which generation of computers used Vacuum Tubes?
(a) 1st (b) 2nd (c) 3rd (d) 4th

**Answer: (a) 1st**

**Solution:** The 1st generation of computers (1940-1956) used Vacuum Tubes. Examples: ENIAC, EDVAC, UNIVAC-I, IBM 701. The 2nd generation (1957-1963) used Transistors (IBM 1400, IBM 7094, CDC 1604). The 3rd generation (1964-1971) used Integrated Circuits (ICs) (IBM System/360, PDP-8). The 4th generation (1971-1985) used Microprocessors (VLSI) (IBM PC, Apple II). The 5th generation (1985-present) uses ULSI, AI-based technology (IBM Watson, AI systems). Generations are based on the underlying technology used.

### Q5. Microprocessors were introduced in which generation of computers?
(a) 1st (b) 2nd (c) 3rd (d) 4th

**Answer: (d) 4th**

**Solution:** Microprocessors (VLSI - Very Large Scale Integration) were introduced in the 4th generation of computers (1971-1985). Examples: IBM PC, Apple II. The 1st generation used Vacuum Tubes (1940-1956). The 2nd generation used Transistors (1957-1963). The 3rd generation used Integrated Circuits - ICs (1964-1971). The 5th generation (1985-present) uses ULSI (Ultra Large Scale Integration), AI-based technology. The invention of the microprocessor by Intel (4004 in 1971) revolutionized computing by integrating thousands of transistors on a single chip.

### Q6. Which is volatile memory?
(a) ROM (b) RAM (c) HDD (d) SSD

**Answer: (b) RAM**

**Solution:** RAM (Random Access Memory) is volatile memory. Data is lost when power is turned off. RAM is the primary memory directly accessed by the CPU. Types: SRAM (Static RAM - faster, used for cache) and DRAM (Dynamic RAM - needs periodic refresh, used for main memory). ROM (Read Only Memory) is non-volatile and stores boot instructions (firmware/BIOS). HDD (Hard Disk Drive) and SSD (Solid State Drive) are non-volatile secondary storage. Volatile memory is faster but loses data on power off. Non-volatile memory retains data without power.

### Q7. Which memory uses flip-flops?
(a) DRAM (b) SRAM (c) ROM (d) HDD

**Answer: (b) SRAM**

**Solution:** SRAM (Static RAM) uses flip-flops (typically 6 transistors per bit) to store each bit. SRAM is faster than DRAM but more expensive and lower density. SRAM is used in CPU cache memory (L1, L2, L3). SRAM does not need periodic refresh, unlike DRAM. DRAM (Dynamic RAM) uses a single transistor and capacitor per bit, and needs periodic refresh. DRAM is used as main memory. ROM (Read Only Memory) is non-volatile and stores boot firmware. HDD (Hard Disk Drive) is magnetic storage and is non-volatile.

### Q8. EPROM is erased by:
(a) Heat (b) UV light (c) Magnetic field (d) Electric current

**Answer: (b) UV light**

**Solution:** EPROM (Erasable Programmable Read Only Memory) is erased by UV (ultraviolet) light. EPROM is a type of ROM that can be erased and reprogrammed. The EPROM chip has a quartz window through which UV light is shone to erase the data. Once erased, EPROM can be reprogrammed using a special device. Other ROM types: ROM (programmed at factory, cannot be erased), PROM (Programmable ROM - can be programmed once), EPROM (UV erasable, reprogrammable), EEPROM (Electrically Erasable PROM - can be erased with electric current; used for BIOS updates). Flash memory is a type of EEPROM.

### Q10. UNIX was developed at:

### Q11. 1 GB equals:
(a) 1024 Bytes (b) 1024 KB (c) 1024 MB (d) 1024 TB

**Answer: (c) 1024 MB**

**Solution:** 1 GB (Gigabyte) = 1024 MB. The data measurement units are: 1 Bit = 0 or 1; 1 Nibble = 4 bits; 1 Byte = 8 bits; 1 KB (Kilobyte) = 1024 Bytes; 1 MB (Megabyte) = 1024 KB; 1 GB (Gigabyte) = 1024 MB; 1 TB (Terabyte) = 1024 GB; 1 PB (Petabyte) = 1024 TB. Note: The SI standard uses 1000 (decimal) instead of 1024 (binary) for kilobyte, megabyte, etc., but in common usage for computer memory, 1024 is used. RAM and storage devices typically use these binary multiples.

### Q12. Cache memory is located:
(a) On motherboard (b) Inside CPU (c) In RAM (d) In HDD

**Answer: (b) Inside CPU**

**Solution:** Cache memory is located inside the CPU (in modern processors). Cache is a high-speed memory between the CPU and RAM. It holds frequently used instructions and data. Modern CPUs have multiple levels of cache: L1 (smallest, fastest, in CPU core), L2 (larger than L1), and L3 (largest, shared across cores). Cache is volatile memory. It significantly speeds up computer operations by reducing the need to access slower RAM. The first CPU with on-chip cache was Intel 486 (1989). The cache size is typically L1 = 32-64 KB, L2 = 256 KB - 1 MB, L3 = 2-32 MB in modern CPUs.

### Q13. Blu-ray disc capacity is:
(a) 700 MB (b) 4.7 GB (c) 8.5 GB (d) 17 GB

**Answer: (d) 17 GB**

**Solution:** Blu-ray disc capacity is ~17 GB (single-layer). Blu-ray uses a blue laser (shorter wavelength than CD/DVD) to read smaller pits, allowing more data. Other optical storage: CD (Compact Disc) ~700 MB; DVD (Digital Versatile Disc) 4.7 GB (single-layer) / 8.5 GB (dual-layer); Blu-ray 17 GB (single-layer) / 25 GB (single-layer in some formats) / 50 GB (dual-layer). Blu-ray was developed by the Blu-ray Disc Association and is commonly used for high-definition video storage. 4K Ultra HD Blu-ray can store up to 100 GB.

### Q15. Flash memory was invented by:
(a) Jack Kilby (b) Robert Noyce (c) Dr. Fujio Masuoka (d) Steve Wozniak

**Answer: (c) Dr. Fujio Masuoka**

**Solution:** Flash memory was invented by Dr. Fujio Masuoka, a Japanese engineer at Toshiba, in the 1980s. He developed flash memory while looking for a replacement for existing EPROM/EEPROM memory. Flash memory is non-volatile and can be electrically erased and reprogrammed. Flash memory is widely used in SSDs, USB pen drives, memory cards (SD cards), smartphones, and other portable devices. NOR flash and NAND flash are the two main types. Jack Kilby and Robert Noyce co-invented the integrated circuit (IC). Steve Wozniak co-founded Apple.
