### Q1. A Firewall operates as:
(a) First line of defense (b) Backup system (c) Hardware only (d) Software only

**Answer: (a) First line of defense**

**Solution:** A Firewall is the first line of defense in network security. It monitors incoming and outgoing traffic and blocks unauthorized access based on predefined security rules. A firewall can be hardware or software. Types: Packet-filtering (examines packets), Stateful Inspection (tracks active connections), Application-level Gateway/Proxy (filters at application layer), Next-Generation Firewall (NGFW) - deep packet inspection, IPS. Modern firewalls include intrusion detection/prevention (IDS/IPS). CERT-In is the Indian Computer Emergency Response Team. Other security tools: Antivirus, VPN, SIEM, DLP, Honeypot. Network security is essential to protect data and systems.

### Q2. AES stands for:
(a) Advanced Encryption Standard (b) American Encryption System (c) Applied Encryption Standard (d) Advanced Electronic Security

**Answer: (a) Advanced Encryption Standard**

**Solution:** AES stands for Advanced Encryption Standard. It is a symmetric encryption algorithm (same key for encryption and decryption). AES key sizes: 128, 192, or 256 bits. AES is the modern standard for symmetric encryption and is widely used (e.g., HTTPS, Wi-Fi WPA2, BitLocker, file encryption). AES replaced DES (Data Encryption Standard) which is now considered insecure due to its 56-bit key. Other symmetric algorithms: DES, 3DES, RC4. Asymmetric algorithms: RSA, ECC, Diffie-Hellman. Hash algorithms: MD5 (insecure), SHA-1 (insecure), SHA-256 (secure). AES is the most widely used symmetric cipher today.

### Q3. The Binary number system has base:
(a) 2 (b) 8 (c) 10 (d) 16

**Answer: (a) 2**

**Solution:** The Binary number system has base 2. It uses only two digits: 0 and 1. Each digit is a "bit" (binary digit). 8 bits = 1 byte. Binary is the internal language of computers. Number systems: Binary (base 2, digits 0-1), Octal (base 8, digits 0-7), Decimal (base 10, digits 0-9), Hexadecimal (base 16, digits 0-9 and A-F). Hexadecimal is widely used in computing for memory addresses and color codes. Each hex digit = 4 binary bits. Each octal digit = 3 binary bits. Conversions: Binary to Decimal (position values), Decimal to Binary (repeated division by 2).

### Q4. The Hexadecimal number system has base:
(a) 2 (b) 8 (c) 10 (d) 16

**Answer: (d) 16**

**Solution:** The Hexadecimal number system has base 16. It uses 16 digits: 0-9 and A-F (A=10, B=11, C=12, D=13, E=14, F=15). Hexadecimal is widely used in computing for memory addresses, color codes (HTML/CSS), and machine code. Each hex digit = 4 binary bits. Hexadecimal is more compact than binary (1 hex digit = 4 binary digits). Common uses: MAC addresses (e.g., 00:1A:2B:3C:4D:5E), IP addresses in IPv6, color codes (#FF0000 for red), memory dumps. Examples: 0xFF = 255 in decimal, 0x10 = 16 in decimal.

### Q5. The Hexadecimal uses digits:
(a) 0-9 (b) 0-9, A-F (c) 0-7 (d) 0-9, A-Z

**Answer: (b) 0-9, A-F**

**Solution:** The Hexadecimal number system uses digits 0-9 and letters A-F. A=10, B=11, C=12, D=13, E=14, F=15. Hexadecimal is base 16. Examples: 0xFF = 255 in decimal (F=15; 15×16 + 15 = 255). 0x10 = 16 in decimal. Hexadecimal is widely used in computing because it is more compact than binary and easier to read. Each hex digit represents 4 binary bits. Hexadecimal is used in memory addresses, MAC addresses, IPv6 addresses, and color codes. The prefix "0x" is used to indicate hex values in programming languages (C, C++, Java, JavaScript, Python).

### Q6. Ransomware:
(a) Steals passwords (b) Encrypts files; demands ransom (c) Slows computer (d) Shows ads

**Answer: (b) Encrypts files; demands ransom**

**Solution:** Ransomware is a type of malware that encrypts the victim's files and demands a ransom (usually in cryptocurrency) for the decryption key. Examples: WannaCry (2017 global attack), Petya/NotPetya (2017), Bad Rabbit (2017), Locky, Cerber. Ransomware attacks have become increasingly common, targeting businesses, hospitals, and government agencies. Notable attacks: WannaCry affected 230,000+ computers in 150 countries in 2017. To protect against ransomware: regular backups, software updates, anti-malware, email security awareness, and not paying the ransom (no guarantee of file recovery). Recent trends include Ransomware-as-a-Service (RaaS) and double extortion (encrypting and threatening to leak data).

### Q7. Phishing is:
(a) Type of virus (b) Fraudulent attempt to steal info (c) Hardware attack (d) Network speedup

**Answer: (b) Fraudulent attempt to steal info**

**Solution:** Phishing is a fraudulent attempt to obtain sensitive information (passwords, credit card numbers, etc.) by disguising as a trustworthy entity in electronic communication (usually email). Types of phishing: Spear Phishing (targeted), Whaling (targeting executives), Vishing (voice phishing - phone calls), Smishing (SMS phishing). Common signs of phishing: urgent or threatening language, mismatched URLs, spelling errors, requests for sensitive information, unexpected attachments. Protection: Be cautious, verify sender, don't click suspicious links, use anti-phishing filters in email, enable 2FA. Anti-Phishing Working Group (APWG) tracks phishing trends globally.

### Q8. SSL/TLS is used for:
(a) Email (b) Encryption on web (c) Database (d) Programming

**Answer: (b) Encryption on web**

**Solution:** SSL/TLS (Secure Sockets Layer/Transport Layer Security) is used for encryption on the web. TLS is the modern version (SSL is deprecated). TLS provides confidentiality, integrity, and authentication for web traffic. HTTPS (HTTP over TLS) uses port 443. TLS 1.3 is the current standard (2024). TLS uses both symmetric (AES) and asymmetric (RSA, ECC) encryption. TLS handshake establishes a secure session between client and server. Digital certificates issued by Certificate Authorities (CAs) verify the server's identity. SSL was developed by Netscape in the 1990s. TLS 1.0 (1999), TLS 1.1 (2006), TLS 1.2 (2008), TLS 1.3 (2018).

### Q9. The binary 1101 in decimal is:
(a) 11 (b) 12 (c) 13 (d) 14

**Answer: (c) 13**

**Solution:** Binary 1101 in decimal is 13. Conversion: 1101₂ = (1×2³) + (1×2²) + (0×2¹) + (1×2⁰) = 8 + 4 + 0 + 1 = 13. The position values for binary digits are powers of 2: starting from the rightmost digit (2⁰), going left (2¹, 2², 2³, etc.). Other conversions: 1010₂ = 10, 1111₂ = 15, 10000₂ = 16, 10101₂ = 21, 11000₂ = 24, 11001₂ = 25. Binary to Decimal conversion is fundamental in computing. The binary number system is the foundation of digital electronics and computer operations.

### Q10. The decimal 25 in binary is:
(a) 11001 (b) 10101 (c) 11010 (d) 10011

**Answer: (a) 11001**

**Solution:** The decimal 25 in binary is 11001. Conversion using repeated division by 2: 25 ÷ 2 = 12 r 1; 12 ÷ 2 = 6 r 0; 6 ÷ 2 = 3 r 0; 3 ÷ 2 = 1 r 1; 1 ÷ 2 = 0 r 1. Read remainders bottom to top: 11001₂. Verification: 11001₂ = 16 + 8 + 0 + 0 + 1 = 25. Other conversions: 10₁₀ = 1010₂, 15₁₀ = 1111₂, 20₁₀ = 10100₂, 50₁₀ = 110010₂, 100₁₀ = 1100100₂, 255₁₀ = 11111111₂. The Decimal to Binary conversion is fundamental in computing. Computer programmers often work with binary, octal, and hexadecimal number systems.

Hexadecimal is widely used in computing for memory addresses, color codes, MAC addresses, and IPv6 addresses. It is more compact and readable than binary.

### Q12. 1 byte equals how many bits?
(a) 4 (b) 8 (c) 16 (d) 32

**Answer: (b) 8**

**Solution:** 1 byte = 8 bits. A bit (Binary digit) is the smallest unit of data (0 or 1). A byte is 8 bits and can represent 256 different values (2⁸ = 256). Data measurement units: 1 Bit = 0 or 1; 1 Nibble = 4 bits; 1 Byte = 8 bits; 1 KB (Kilobyte) = 1024 Bytes; 1 MB (Megabyte) = 1024 KB; 1 GB (Gigabyte) = 1024 MB; 1 TB (Terabyte) = 1024 GB; 1 PB (Petabyte) = 1024 TB. ASCII uses 7-8 bits per character. Unicode uses 16-32 bits per character. Modern computers process data in 64-bit chunks (64-bit processors).

### Q13. 1 nibble equals how many bits?
(a) 2 (b) 4 (c) 6 (d) 8

**Answer: (b) 4**

**Solution:** 1 nibble = 4 bits. A nibble (also called a "nybble") is half a byte. A nibble can represent 16 different values (2⁴ = 16). Hexadecimal uses one nibble per digit (each hex digit = 4 bits). Octal uses 3 bits per digit. Data measurement units: 1 Bit = 0 or 1; 1 Nibble = 4 bits; 1 Byte = 8 bits (2 nibbles); 1 KB = 1024 Bytes; 1 MB = 1024 KB. The term "nibble" is sometimes used in computing for half a byte. The hexadecimal representation is more compact and human-readable than binary.

### Q14. The ASCII value of 'A' is:
(a) 48 (b) 65 (c) 97 (d) 100

**Answer: (b) 65**

**Solution:** The ASCII (American Standard Code for Information Interchange) value of 'A' (uppercase) is 65. ASCII is a 7-bit code (128 characters). Common ASCII values: 'A' = 65, 'Z' = 90, 'a' = 97, 'z' = 122, '0' = 48, '9' = 57, space = 32, Enter = 13, Tab = 9, '!' = 33, '@' = 64. Extended ASCII uses 8 bits (256 characters). Unicode supports all languages and emojis and is the modern standard. UTF-8 is the most common Unicode implementation (variable length 1-4 bytes). Unicode values: 'A' is U+0041, '₹' (Rupee) is U+20B9, '✓' is U+2713.

### Q15. The Trojan Horse is:
(a) Self-replicating (b) Disguised as legitimate (c) Encrypts files (d) Spreads via email

**Answer: (b) Disguised as legitimate**

**Solution:** The Trojan Horse (or simply Trojan) is malware that is disguised as legitimate software. Unlike viruses and worms, Trojans do not self-replicate. They rely on the user to install them by being tricked. Common types: Remote Access Trojan (RAT), Banking Trojan, Downloader Trojan, Fake AV. Once installed, Trojans can steal data, install other malware, or give attackers remote access. Examples: Emotet, Zeus (banking Trojan), Agent Tesla. The name comes from the Greek Trojan Horse story. To protect: be cautious of unknown software, use reputable sources, keep anti-malware updated. Other malware types: Virus (needs host, self-replicates with host), Worm (self-replicates, no host needed), Ransomware (encrypts files for ransom), Spyware (monitors user).
