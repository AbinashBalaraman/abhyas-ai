### Q1. The full form of CPU is:
(a) Central Processing Unit (b) Common Processing Unit (c) Computer Processing Unit (d) Central Program Unit

**Answer: (a) Central Processing Unit**

**Solution:** CPU stands for Central Processing Unit. It is the brain of the computer. The CPU has three main components: ALU (Arithmetic Logic Unit - performs arithmetic and logical operations), CU (Control Unit - controls and coordinates computer operations), and Registers (high-speed memory inside CPU for temporary storage). The CPU follows the Fetch-Decode-Execute cycle. Modern CPUs have multiple cores (dual-core, quad-core, octa-core) and threads. CPU speed is measured in GHz (Gigahertz). The first commercial CPU was the Intel 4004 (1971).

### Q2. RAM is:
(a) Read Access Memory (b) Random Access Memory (c) Random Address Memory (d) Read Address Memory

**Answer: (b) Random Access Memory**

**Solution:** RAM stands for Random Access Memory. RAM is volatile primary memory that can be accessed randomly (any byte directly). RAM is used as the main memory of the computer, holding data and instructions currently being used. RAM types: SRAM (Static RAM - faster, used for cache) and DRAM (Dynamic RAM - cheaper, used as main memory). RAM is faster than secondary storage (HDD, SSD) but loses data on power off. Modern computers typically have 4-32 GB of RAM. DDR (Double Data Rate) SDRAM is the current standard.

### Q3. The full form of ROM is:
(a) Random Only Memory (b) Read Only Memory (c) Read Output Memory (d) Run Only Memory

**Answer: (b) Read Only Memory**

**Solution:** ROM stands for Read Only Memory. ROM is non-volatile memory that retains data without power. ROM is used to store boot instructions (firmware/BIOS) and other permanent data. ROM types: ROM (programmed at factory, cannot be erased), PROM (Programmable ROM - can be programmed once), EPROM (Erasable PROM - erased by UV light, can be reprogrammed), EEPROM (Electrically Erasable PROM - erased by electric current, used for BIOS updates). Flash memory is a type of EEPROM. Modern computers use flash-based ROM (e.g., UEFI BIOS).

### Q4. The 1st generation computers used:
(a) Transistors (b) Vacuum Tubes (c) ICs (d) Microprocessors

**Answer: (b) Vacuum Tubes**

**Solution:** The 1st generation of computers (1940-1956) used Vacuum Tubes. Examples: ENIAC, EDVAC, UNIVAC-I, IBM 701. Vacuum tubes were large, generated a lot of heat, and were unreliable. The 2nd generation (1957-1963) used Transistors. The 3rd generation (1964-1971) used Integrated Circuits (ICs). The 4th generation (1971-1985) used Microprocessors (VLSI). The 5th generation (1985-present) uses ULSI and AI-based technology. Vacuum tubes were eventually replaced by transistors (invented in 1947 at Bell Labs).

### Q5. SSD stands for:
(a) Solid State Drive (b) Standard State Drive (c) Solid Storage Disk (d) Solid State Disk

**Answer: (a) Solid State Drive**

**Solution:** SSD stands for Solid State Drive. SSD uses flash memory (NAND flash) to store data. SSD has no moving parts, making it faster (μs access time) than HDD (ms access time), more durable, and lighter. SSD consumes less power than HDD. SSD is more expensive per GB than HDD. SSD uses interfaces like SATA, NVMe (PCIe). Modern NVMe SSDs can reach read/write speeds of 7,000+ MB/s. HDD (Hard Disk Drive) uses magnetic platters and has moving parts. SSD is the preferred storage for performance, while HDD is preferred for bulk storage.

### Q10. The BIOS is:
(a) Basic Input Output System (b) Basic Internal Output Software (c) Binary Input Output System (d) Basic Integrated Operating System

**Answer: (a) Basic Input Output System**

**Solution:** BIOS stands for Basic Input Output System. BIOS is firmware stored in ROM/flash memory on the motherboard. It performs the POST (Power-On Self-Test) when the computer is turned on, initializes hardware, and loads the operating system. Modern computers use UEFI (Unified Extensible Firmware Interface) instead of legacy BIOS, but the term "BIOS" is still commonly used. The BIOS/UEFI provides low-level control over hardware settings (boot order, CPU clock, RAM timings, etc.). The BIOS is a critical component of the computer's boot process.
