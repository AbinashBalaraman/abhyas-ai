### Q1. Statements:
S1: All A are B.
S2: No B is C.
S3: All D are C.
Conclusions:
I. No A is C.
II. Some D are not B.
(a) Only I (b) Only II (c) Both (d) Neither

**Answer:** (c) Both
**Solution:** A inside B. B separate from C. So A separate from C. ✓ I. D inside C, C separate from B. So D separate from B. ✓ II.
**Time Target:** 40 sec |

### Q2. Statements:
S1: Some A are B.
S2: All B are C.
S3: No C is D.
Conclusions:
I. Some A are not D.
II. All C being non-D, B is also non-D.
(a) Only I (b) Only II (c) Both (d) Either/Or

**Answer:** (a) Only I
**Solution:** A ∩ B ≠ ∅. B inside C. C separate from D. So B and A also separate from D. I: ✓. II: "All C being non-D, B is also non-D" is the same as saying B is non-D, which is implied, not concluded. **Answer: (a) Only I.**
**Time Target:** 45 sec |

### Q4. Statements:
S1: No X is Y.
S2: All Y are Z.
Conclusions:
I. No X is Z.
II. Some Z are not X.
(a) Only I (b) Only II (c) Both (d) Either/Or

**Answer:** (b) Only II
**Solution:** I: X separate from Y, but Y inside Z. X may overlap with Z (X is not Y, but X could be in Z if Z extends beyond Y). Doesn't follow. II: "No X is Y" → "Some Y are not X" → "All Y are Z, some Y" → "Some Z (the Y part) are not X" ✓.
**Time Target:** 45 sec |

### Q5. Statements:
S1: All A are B.
S2: All B are C.
S3: Some C are D.
Conclusions:
I. Some A are D.
II. Some D are B.
(a) Only I (b) Only II (c) Both (d) Neither

**Answer:** (d) Neither
**Solution:** A → B → C. C ∩ D ≠ ∅. The D part of C may or may not include the B (and A) part. No definite conclusion.

### Q6. Statements:
S1: Some X are Y.
S2: All Y are Z.
S3: All Z are W.
Conclusions:
I. Some X are W.
II. All X are W.
(a) Only I (b) Only II (c) Both (d) Neither

**Answer:** (a) Only I
**Solution:** X ∩ Y ≠ ∅. Y inside Z inside W. So X ∩ W ≠ ∅ ✓. I: ✓. II: not all X are W (X may have parts outside Y).
**Time Target:** 45 sec |

### Q7. Statements:
S1: All M are N.
S2: Some N are O.
S3: All O are P.
Conclusions:
I. Some M are P.
II. Some P are N.
(a) Only I (b) Only II (c) Both (d) Neither

**Answer:** (b) Only II
**Solution:** M inside N. N ∩ O ≠ ∅. O inside P. The N part of O is in P, so some P are N ✓. I: M is in N but the M part may not be in N∩O. Doesn't follow.

### Q11. Statements:
S1: All P are Q.
S2: No Q is R.
S3: Some S are R.
Conclusions:
I. Some S are not P.
II. No P is S.
(a) Only I (b) Only II (c) Both (d) Either/Or

**Answer:** (a) Only I
**Solution:** P inside Q. Q separate from R. S ∩ R ≠ ∅. S has parts in R, R is separate from Q, so S has parts not in Q. Since P is in Q, these S parts are not P. I ✓. II: P is in Q, but S may also be in Q (different from R parts). Doesn't follow.
