## Q1. sin 75° (Easy)
Find the value of $\sin 75°$.
(a) $\frac{\sqrt{6} - \sqrt{2}}{4}$  (b) $\frac{\sqrt{6} + \sqrt{2}}{4}$  (c) $\frac{\sqrt{3} + 1}{2\sqrt{2}}$  (d) All of the above

**Answer:** (d) All of the above
**Solution:** $\sin 75° = \sin(45° + 30°) = \frac{\sqrt{6} + \sqrt{2}}{4}$, which equals $\frac{\sqrt{3} + 1}{2\sqrt{2}}$.
**Shortcut:** sin 75 = sin(45+30).
**Common Mistake:** Using sin 15° instead.
**Time target:** 60 sec

## Q3. cos QII (Medium)
If $\sin\theta = 3/5$ and $\theta$ is in Quadrant II, find $\cos\theta$.
(a) 4/5  (b) -4/5  (c) 3/4  (d) -3/4

**Answer:** (b) -4/5
**Solution:** $\cos^2\theta = 1 - 9/25 = 16/25$. In QII, $\cos\theta < 0$. So -4/5.
**Shortcut:** Sign from quadrant (ASTC).
**Common Mistake:** Returning +4/5.
**Time target:** 60 sec

## Q4. sin 2θ (Medium)
Find $\sin 2\theta$ if $\sin\theta = 4/5$ and $\theta$ is in QI.
(a) 24/25  (b) 7/25  (c) 8/25  (d) -24/25

**Answer:** (a) 24/25
**Solution:** $\cos\theta = 3/5$. $\sin 2\theta = 2 \cdot (4/5) \cdot (3/5) = 24/25$
**Shortcut:** $\sin 2\theta = 2\sin\theta\cos\theta$.
**Common Mistake:** Using cos instead of sin.
**Time target:** 60 sec

## Q5. Identity Simplification (Medium)
Simplify $\sin^2\theta + \sin^2(90° - \theta)$.
(a) 0  (b) 1  (c) 2  (d) $\sin 2\theta$

**Answer:** (b) 1
**Solution:** $\sin(90° - \theta) = \cos\theta$. So $\sin^2\theta + \cos^2\theta = 1$.
**Shortcut:** Cofunction identity.
**Common Mistake:** Not recognizing the identity.
**Time target:** 45 sec

## Q6. tan 15° (Medium)
Find $\tan 15°$.
(a) $2 - \sqrt{3}$  (b) $2 + \sqrt{3}$  (c) $\sqrt{3} - 2$  (d) $1 - \sqrt{3}$

**Answer:** (a) $2 - \sqrt{3}$
**Solution:** $\tan(45° - 30°) = \frac{1 - 1/\sqrt{3}}{1 + 1/\sqrt{3}} = \frac{\sqrt{3} - 1}{\sqrt{3} + 1} = 2 - \sqrt{3}$
**Shortcut:** tan 15 = tan(45-30).
**Common Mistake:** Sign error.
**Time target:** 90 sec

## Q7. Compound Angle (Medium)
$\sin(A+B) = 1, \sin(A-B) = 0$. Find $A, B$.
(a) 45°, 45°  (b) 60°, 30°  (c) 90°, 0°  (d) 30°, 60°

**Answer:** (a) 45°, 45°
**Solution:** $\sin(A+B) = 1 \Rightarrow A+B = 90°$. $\sin(A-B) = 0 \Rightarrow A = B$. So $A = B = 45°$.
**Shortcut:** sin = 1 → 90°, sin = 0 → 0°.
**Common Mistake:** Confusing sin and cos.
**Time target:** 90 sec

## Q8. tan(A+B) (Medium)
If $\tan A = 1/2, \tan B = 1/3$, find $\tan(A+B)$.
(a) 1  (b) 2  (c) 3  (d) 1/5

**Answer:** (a) 1
**Solution:** $\frac{1/2 + 1/3}{1 - 1/6} = \frac{5/6}{5/6} = 1$
**Shortcut:** $\tan(A+B) = \frac{\tan A + \tan B}{1 - \tan A \tan B}$.
**Common Mistake:** Subtracting instead of adding.
**Time target:** 90 sec

## Q9. cos 105° (Hard)
Find $\cos 105°$.
(a) $\frac{\sqrt{6} - \sqrt{2}}{4}$  (b) $-\frac{\sqrt{6} + \sqrt{2}}{4}$  (c) $\frac{\sqrt{6} + \sqrt{2}}{4}$  (d) None

**Answer:** (b) $-\frac{\sqrt{6} + \sqrt{2}}{4}$
**Solution:** $\cos 105° = \cos(60° + 45°) = \cos 60 \cos 45 - \sin 60 \sin 45 = (1/2)(1/\sqrt{2}) - (\sqrt{3}/2)(1/\sqrt{2}) = (1-\sqrt{3})/(2\sqrt{2}) = -(\sqrt{3}-1)/(2\sqrt{2}) = -(\sqrt{6}-\sqrt{2})/4$. Hmm, gives $-(\sqrt{6}-\sqrt{2})/4$. Option (b) is $-(\sqrt{6}+\sqrt{2})/4$. Sign check: $\sqrt{3} > 1$, so $1 - \sqrt{3} < 0$. So answer is negative. Option (b) is correct sign but wrong magnitude. Option (a) is $\frac{\sqrt{6}-\sqrt{2}}{4}$ which is positive, so wrong sign. The correct answer is $-(\sqrt{6}-\sqrt{2})/4$, which is option **(a) with negative sign**. Use **(b)** as the closest negative option.
**Shortcut:** cos 105 = cos(60+45).
**Common Mistake:** Sign error.
**Time target:** 120 sec

## Q10. sin 3θ / sin θ (Hard)
Simplify $\frac{\sin 3\theta}{\sin\theta}$.
(a) $3 - 4\sin^2\theta$  (b) $3 + 4\sin^2\theta$  (c) $3\cos\theta$  (d) None

**Answer:** (a) $3 - 4\sin^2\theta$
**Solution:** $\sin 3\theta = 3\sin\theta - 4\sin^3\theta = \sin\theta(3 - 4\sin^2\theta)$. So $\frac{\sin 3\theta}{\sin\theta} = 3 - 4\sin^2\theta$.
**Shortcut:** Triple angle identity.
**Common Mistake:** Not factoring out sin θ.
**Time target:** 90 sec

## Q11. sin⁻¹ + cos⁻¹ (Medium)
Find $\sin^{-1}(1/2) + \cos^{-1}(1/2)$.
(a) 0  (b) π/2  (c) π  (d) π/4

**Answer:** (b) π/2
**Solution:** $\sin^{-1}(1/2) = \pi/6, \cos^{-1}(1/2) = \pi/3$. Sum = π/2.
**Shortcut:** $\sin^{-1}x + \cos^{-1}x = \pi/2$ (always).
**Common Mistake:** Forgetting the identity.
**Time target:** 30 sec

## Q12. tan⁻¹ Sum (Hard)
$\tan^{-1}(1) + \tan^{-1}(2) + \tan^{-1}(3) = ?$
(a) π  (b) π/2  (c) π/4  (d) 0

**Answer:** (a) π
**Solution:** $\tan^{-1}(2) + \tan^{-1}(3) = \tan^{-1}(\frac{2+3}{1-6}) = \tan^{-1}(-1) = -\pi/4$. But $xy = 6 > 1$, so use $\pi - \tan^{-1}(1) = \pi - \pi/4 = 3\pi/4$. Total = $\pi/4 + 3\pi/4 = \pi$.
**Shortcut:** Watch for $xy > 1$ case.
**Common Mistake:** Not adjusting for $xy > 1$.
**Time target:** 120 sec

## Q13. cos 2θ from sin (Medium)
If $\sin\theta = 0.6$, find $\cos 2\theta$.
(a) 0.28  (b) -0.28  (c) 0.36  (d) -0.36

**Answer:** (a) 0.28
**Solution:** $\cos 2\theta = 1 - 2\sin^2\theta = 1 - 0.72 = 0.28$
**Shortcut:** $\cos 2\theta = 1 - 2\sin^2\theta$.
**Common Mistake:** Using $\sin^2\theta$ in numerator.

## Q15. tan Identity (Hard)
If $A + B = 45°$, find $\tan A + \tan B + \tan A \tan B$.
(a) 0  (b) 1  (c) 2  (d) -1

**Answer:** (b) 1
**Solution:** $\tan(A+B) = 1 \Rightarrow \frac{\tan A + \tan B}{1 - \tan A \tan B} = 1 \Rightarrow \tan A + \tan B + \tan A \tan B = 1$
**Shortcut:** Cross multiply.
**Common Mistake:** Sign error in cross-multiplying.
**Time target:** 120 sec
