### Q1. Ctrl + M in PowerPoint is used to:
(a) New slide (b) Move slide (c) Merge slides (d) Mark slide

**Answer: (a) New slide**

**Solution:** Ctrl + M in MS PowerPoint is used to insert a new slide. The new slide is added after the current slide. Other PowerPoint shortcuts: Ctrl + N (New presentation), Ctrl + O (Open), Ctrl + S (Save), Ctrl + D (Duplicate current slide), Ctrl + P (Print), F5 (Start slideshow from beginning), Shift + F5 (Start from current slide), Esc (End slideshow), B (Black screen), W (White screen), Ctrl + T (Insert table). MS PowerPoint is the most popular presentation software, developed by Microsoft. It uses slides for visual storytelling.

### Q2. The maximum font size in MS Word (automatic) is:
(a) 50 (b) 72 (c) 100 (d) 1638

**Answer: (b) 72**

**Solution:** The maximum font size in MS Word (automatic) is 72 points. The maximum manual size is 1638 points. The minimum font size (auto) is 8 points; manual is 1 point. MS Word allows you to set font size in points. Common font sizes: 8, 9, 10, 11, 12, 14, 16, 18, 20, 24, 28, 36, 48, 72 points. The default font is Calibri 11. The default settings can be customized in MS Word's options. Font size affects the appearance of text in the document. Larger sizes are used for headings; smaller sizes for footnotes.

### Q4. A Foreign Key refers to:
(a) Another database (b) Primary key of another table (c) Primary key of same table (d) Index

**Answer: (b) Primary key of another table**

**Solution:** A Foreign Key refers to the Primary Key of another table. The Foreign Key establishes a relationship between two tables in a relational database. It enforces referential integrity — every value in the Foreign Key column must either match a value in the referenced Primary Key column or be NULL. Foreign Keys can be added during table creation (CREATE TABLE) or later (ALTER TABLE). The table containing the Foreign Key is the "child" or "referencing" table; the table with the Primary Key is the "parent" or "referenced" table. Foreign Keys enable joins between tables and maintain data consistency.

### Q5. DCL in SQL includes:
(a) INSERT, UPDATE (b) GRANT, REVOKE (c) CREATE, DROP (d) SELECT, DELETE

**Answer: (b) GRANT, REVOKE**

**Solution:** DCL (Data Control Language) in SQL includes GRANT and REVOKE. GRANT gives permissions to users (e.g., SELECT, INSERT, UPDATE, DELETE on a table). REVOKE takes back those permissions. DCL is used to manage database security and access control. The other SQL sub-languages: DDL (Data Definition Language) - CREATE, ALTER, DROP, TRUNCATE; DML (Data Manipulation Language) - SELECT, INSERT, UPDATE, DELETE; TCL (Transaction Control Language) - COMMIT, ROLLBACK, SAVEPOINT. These 4 sub-languages form the complete SQL command set. SQL is standardized by ANSI/ISO.

### Q6. The Excel cell reference A1 in =A1 is what type when copied?
(a) Absolute (b) Relative (c) Mixed (d) Static

**Answer: (b) Relative**

**Solution:** A1 in =A1 is a Relative cell reference. When copied, the reference changes relatively (A1 → A2 → B1, etc.). To make it absolute, use $A$1. The cell reference types in Excel: Relative (A1) - changes when copied; Absolute ($A$1) - doesn't change when copied; Mixed ($A1 or A$1) - part changes when copied. The $ symbol makes the column or row reference absolute. Absolute references are useful for constants (e.g., tax rates, conversion factors). F4 toggles between reference types in formula editing mode.

### Q9. SQL JOIN that returns only matching rows from both tables is:
(a) LEFT JOIN (b) INNER JOIN (c) RIGHT JOIN (d) FULL JOIN

**Answer: (b) INNER JOIN**

**Solution:** INNER JOIN returns only the matching rows from both tables. Other SQL JOINs: LEFT (OUTER) JOIN - returns all rows from the left table and matching rows from the right; RIGHT (OUTER) JOIN - returns all rows from the right table and matching rows from the left; FULL OUTER JOIN - returns all rows from both tables; CROSS JOIN - returns the Cartesian product of both tables. The basic syntax: SELECT columns FROM table1 [JOIN TYPE] table2 ON table1.column = table2.column. INNER JOIN is the most common type. SQL JOINs are essential for combining data from multiple tables.

### Q10. The COMMIT command in SQL is used to:
(a) Save changes permanently (b) Undo changes (c) Delete data (d) Add constraints

**Answer: (a) Save changes permanently**

**Solution:** The COMMIT command in SQL is used to save changes permanently to the database. Once COMMIT is executed, the changes cannot be rolled back. ROLLBACK is used to undo uncommitted changes. SAVEPOINT creates a point within a transaction to which you can roll back. These commands are part of TCL (Transaction Control Language). The COMMIT and ROLLBACK commands work with transactions (BEGIN TRANSACTION, COMMIT, ROLLBACK). COMMIT is critical for ensuring data durability (one of the ACID properties). Auto-commit is enabled by default in most database systems.
